# 자미두수 1차 판단

계약: `docs/spec/ziwei-first-pass-judgment.md`. 판단은 에이전트가 하고, 형식과 근거 인용은 검증기가 확인한다.

## 1. 대상 디렉터리

- 사용자가 준 차트 디렉터리, 또는 같은 대화에서 chart-report가 저장한 `chartDir`를 쓴다. 둘 다 없으면 묻는다.
  `artifacts/`를 탐색하거나 최신 버전을 추측하지 않는다.
- `test -e <디렉터리>/ziwei-judgment.md`가 성공하면(이미 있으면) 덮어쓰지 않고 멈춘 뒤 알린다.

## 2. 읽기

같은 디렉터리의 `ziwei-chart.md`와 `ziwei-facts.md`만 읽는다. 사주·네이탈 파일과 다른 버전의 판단 문서는 읽지 않는다.

## 3. 판단과 작성

`<디렉터리>/ziwei-judgment.md`에 아래 형식 그대로 쓴다. 섹션 4개, 순서 고정, 섹션 안에는 `키: 값` 필드 줄만 쓴다.

```markdown
# 紫微斗數 1차 판단

명반: 命宮 <간지> · 身宮 <궁 (지지)> · <오행국>

## 명궁 역량
결론: <강 | 중 | 약>
근거: <인용 1개 이상>
대안: <결론과 다른 허용값> — <설명, 인용 1개 이상>
뒤집힘: <무엇이 달라지면 결론이 대안으로 바뀌는지>

## 격국
결론: <격 이름 또는 없음, 자유 텍스트>
근거: …
대안: …
뒤집힘: …

## 강점 궁
결론: <12궁 이름>
…

## 과제 궁
결론: <12궁 이름>
…
```

- `명반`은 `ziwei-chart.md` 머리의 `命宮`, `身宮`, `五行局` 값을 그대로 옮긴다 (예: `命宮 乙酉 · 身宮 夫妻 (未) · 水二局`).
- 12궁 이름은 `命宮 兄弟 夫妻 子女 財帛 疾厄 遷移 交友 官祿 田宅 福德 父母` 중 하나이고 `宮`을 덧붙이지 않는다.
- 인용은 `[facts:<항목 이름>]`(괄호 안 정의는 빼고, 예: `[facts:궁별 보조성 수]`)과
  `[chart:<절 제목 또는 12궁 이름>]`(예: `[chart:四化]`, `[chart:官祿]`)만 쓴다. 파일에 없는 이름을 만들지 않는다.
- 본명반만 판단한다. `流年`·`流月`·`大限`은 읽더라도 근거로 쓰거나 인용하지 않는다.
- 별 개수·사화 위치·성계 성립 같은 사실은 두 파일에 있는 것만 근거로 쓴다. 파일에 없는 사실을 직접 계산해 넣지 않는다.
- 결론은 하나만 쓴다. 다른 가능성은 `대안`과 `뒤집힘`에 근거와 함께 적는다. 확신도 표시는 쓰지 않는다.
- 강점 궁과 과제 궁은 서로 다른 궁이어야 한다.

## 4. 검증

```bash
bun scripts/check-ziwei-judgment.ts <디렉터리>
```

- 출력이 없고 exit 0이면 끝이다.
- 위반 줄이 나오면 그 줄만 고쳐 다시 실행한다. 3번 고쳐도 통과하지 못하면 멈추고 남은 위반을 그대로 알린다.
- 검증을 통과시키려고 판단 결론을 바꾸지 않는다. 인용 이름이나 형식을 고친다.

## 5. 보고

파일 경로와 섹션별 결론을 한 줄씩 알린다. 문서 본문을 다시 옮겨 쓰지 않는다.
