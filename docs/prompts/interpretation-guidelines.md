# 차트 해석 기준

차트 해석은 후속 개인화 설계의 근거가 되는 삶의 해석이다. 전문 해석 단계에서는 차트 보고서에 기록된 지정 체계의 모든 출력 요소를 다루고, 통합 단계에서는 세 전문 해석의 일관성·구체화·상충을 근거와 함께 설명한다.

## 관찰

- 각 체계에 실제로 기록된 위치, 관계, 분포만 다룬다.
- 보고서의 값을 옮긴 관찰과 그 값에서 도출한 해석을 구분한다.
- 보고서에 기록된 구조를 성격, 적성, 재물 운용 방식, 관계 성향, 배우자상, 가족·대인관계, 건강 경향, 시기별 변화까지 구체적으로 해석한다.
- 사주는 원국 구조·관계 작용·운의 변화, 자미두수는 궁위 역할·성요 상태·시간 층위, 서양 점성술은 심리 기능·삶의 영역·내적 역동을 서로 대체할 수 없는 해상도로 다룬다.

## 종합

- 둘 이상의 체계에서 반복되는 해석은 `일관`, 한 체계가 다른 체계의 범위나 작동 방식을 좁히는 경우는 `구체화`, 함께 유지하기 어려운 경우는 `상충`, 한 체계만 제공하지만 전체 인물상을 깊게 하는 해석은 `고유`로 구분한다.
- 충돌하는 요소는 어느 한쪽을 제거하거나 임의로 화해시키지 않는다.
- 같은 근거가 여러 방향으로 발현될 수 있으면 각각을 삶의 대안적 발현으로 남긴다.
- 정적인 특성 목록보다 요소 사이의 관계와 긴장을 설명한다.
- 공통 해석은 인물의 핵심축으로 강화하되, 각 체계만 제공할 수 있는 근거는 원인·발현 영역·심리적 작동·시기·예외를 좁히는 고유 통찰로 보존한다.
- 세 체계를 같은 말로 평준화하지 않는다. 사주는 구조와 에너지 배분 및 장기 변화, 자미두수는 삶의 궁위와 다층 시기, 서양 점성술은 심리 기능과 내적 역동을 설명하는 데 기여하도록 한다.
- 내적 동기에서 행동 방식, 환경의 반응, 반복 결과로 이어지는 작동 사슬을 만들고 성격·직업·재물·관계·건강·시기 영역 사이의 연결을 밝힌다.
- 같은 성향이 강점과 취약점으로 갈리는 조건을 함께 설명하고, 시간에 걸쳐 유지되는 특성과 계산된 운의 층위에 따라 달라지는 표현을 구분한다.

## 핵심 해석 항목

후속 작업이 필요한 해석을 선택할 수 있도록 주요 종합을 독립된 항목으로 정리한다.

- 통합 항목에는 `I-01`부터 시작하는 고유하고 연속된 ID를 붙인다. 전문 항목은 체계별 템플릿의 `S-01`, `Z-01`, `N-01` 접두사를 따른다.
- `해석:`에는 보고서에서 도출할 수 있는 의미만 간결하게 쓴다.
- 결론을 먼저 쓰고, 그것이 일상에서 어떻게 드러나는지 강점·취약점·조건을 구체적으로 풀어 쓴다. 배치나 축의 이름을 다른 말로 반복하는 데서 멈추지 않는다.
- 전문 문서의 `근거:`에는 `chart-evidence.json`에 있는 해당 체계의 evidence ID만 명시하고, 모든 ID를 문서 전체에서 최소 한 번 사용한다.
- 통합 문서의 `근거:`에는 실제 전문 해석 ID를 명시한다.
- 통합 항목은 하나의 생활 영역에 고립하지 않고 다른 영역과의 연결, 작동 사슬, 강점·취약점의 양면성, 발현 조건을 함께 기록한다.
- 전문 항목은 체계 고유의 `해상도:`를 기록한다.
- 통합 항목은 모든 전문 ID를 최소 한 번 사용하고, 동기·행동·환경 반응·반복 결과·발현 조건을 삶의 해석으로 기록한다.
- 전문 및 통합 단계에서는 주인공 직업, 판타지 능력, 무기, 게임 규칙, 세력, 장소 같은 창작 재료를 제안하거나 확정하지 않는다.

## 출력 규칙

- “영역이 활성화된다”, “축이 전면화된다”, “긴장이 있다” 같은 추상 표현만으로 답을 끝내지 않는다. 무엇을 잘하거나 어려워하는지, 어떤 환경과 상대에게 맞는지, 무엇이 기회나 부담으로 작용하는지까지 답한다.
- 게임 장르, 주인공, 갈등, 관계, 진행, 전투, 지역, 미학 등 후속 창작 요소를 설계하지 않는다.
- 각 결론의 구체성은 실제 근거의 구체성에 맞추고, 근거가 허용하는 발현 방향을 풍부하게 전개한다.

## 전문 해석 템플릿 사용

전문 해석에서는 지정 체계의 질문에 답해 해당 템플릿을 완성한다.
통합 해석은 기존 통합 출력 계약을 사용하며 아래 전문 모드·항목 형식을 적용하지 않는다.

| 체계 | 해석 과제와 출력 템플릿 |
| --- | --- |
| 사주팔자 | [saju-interpretation.md](saju-interpretation.md) |
| 자미두수 | [ziwei-interpretation.md](ziwei-interpretation.md) |
| 네이탈 차트 | [natal-interpretation.md](natal-interpretation.md) |

한국어로 작성하고, 템플릿의 장 제목과 순서를 그대로 사용한다. 각 장의 질문을
실제 답으로 교체하며 관찰과 해석을 구분한다. 원문 행·장식 구분선·근거 검토표를
복제하지 않는다. 근거 ID를 인용하는 것만으로 질문에 답한 것으로 간주하지 않는다.

### 작성 순서

1. **체계 고유 해석**: 체계별 템플릿의 고정 질문에 먼저 답한다. 요소별 관찰과 해석을
   충분히 작성하고, 성격·직업 같은 공통 분류에 맞추기 위해 고유한 내용을 생략하지 않는다.
2. **생활 영역 종합**: 앞에서 해석한 요소들의 반복·결합·긴장을 바탕으로
   `## 전문 해석 항목`을 작성한다. 일곱 영역은 결과를 정리하는 분류이며 해석의 출발점이 아니다.
3. **개인별 부록**: 고정 질문과 일반적인 영역 요약만으로 설명이 부족한 해당 인물의
   특이 조합·상반된 발현·시기 조건을 `## 개인별 부록`에서 추가로 설명한다.

고정되는 것은 질문과 출력 순서다. 해석 결론이나 사람마다의 추가 설명을 고정하지 않는다.
이 단계의 생활 영역 종합은 지정된 한 체계 안에서 수행한다. 세 체계 사이의 공통점 비교는
후속 통합 단계에서 수행한다.

`## 전문 해석 항목`에는 다음 일곱 질문에 모두 답하는 항목을 작성한다.
각 항목의 `영역:`에는 표의 정확한 라벨 중 하나를 사용한다.

| 영역 | 답해야 하는 질문 |
| --- | --- |
| 성격과 기질 | 무엇을 원하고 어떻게 반응하는가? 강점과 취약점은 어떤 조건에서 드러나는가? |
| 직업과 적성 | 어떤 실제 역할·일하는 방식·환경에 맞는가? 어떤 업무 조건에서 마찰이 생기는가? |
| 재물 | 자원을 얻고 쓰고 유지하는 방식은 어떠한가? 축적과 소모를 가르는 조건은 무엇인가? |
| 연애와 배우자 | 어떤 상대와 관계 패턴을 형성하는가? 끌림·지속·갈등에 영향을 주는 조건은 무엇인가? |
| 가족과 대인관계 | 가족·동료·권위자와 어떤 역할과 거리를 형성하는가? 지원과 마찰은 어떻게 나타나는가? |
| 건강과 생활 리듬 | 어떤 활동·회복·생활 관리 패턴이 나타나는가? 부담과 회복의 조건은 무엇인가? |
| 시기운 | 실제로 계산된 시간 층위에서 무엇이 유지되고 바뀌는가? 시기 자료가 없다면 어떤 정적 경향과 발현 조건으로 설명할 수 있는가? |

각 전문 항목은 체계 접두사의 연속 ID와 `영역:`, `해상도:`, `해석:`, `근거:`를
각각 한 줄씩 사용한다. `해석:`은 결론부터 쓰고 근거에 따른 구체적 생활 발현을
최소 80자 이상으로 설명한다. 필요한 만큼 별도 문단을 덧붙일 수 있다.
서로 다른 근거가 필요한 결론은 별도 항목으로 나눈다.

해당 체계의 모든 evidence ID를 전문 항목들의 `근거:`에 최소 한 번 인용한다.
관련된 근거를 묶을 수 있지만 다른 체계의 ID나 임의의 ID는 사용하지 않는다.
관계의 긴장과 대안적 발현을 보존하며 게임 직업·능력·세력·장소 등의 창작 소재나
`시드 가치:`를 추가하지 않는다. 지지되는 해석을 일반적인 면책·책임 회피 문구로 약화하지 않는다.

각 생활 항목에는 어느 앞선 장의 어떤 요소 해석을 종합했는지 드러나야 한다.
요소를 다시 나열하거나 생활 질문에 독립적으로 답을 지어내지 않는다. 한 요소가
여러 생활 영역에 작용할 수 있고, 여러 요소가 같은 영역에서 충돌할 수도 있다.
반복되는 결론뿐 아니라 그 사람에게 중요한 단일 근거와 예외도 남긴다.

### 개인별 부록

부록은 고정 질문에 답한 뒤에도 추가 설명이 필요한 개인 고유의 내용을 담는다.
왜 이 사람에게 설명이 필요한지와 어떤 조건에서 달리 나타나는지를 쓴다.
근거가 없는 특이점이나 일반적인 조언으로 분량을 채우지 않는다.
추가할 내용이 없으면 `추가로 설명할 개인 고유 사항 없음.`이라고 쓴다.

부록에서 중요한 새 결론이 생기면 먼저 적절한 생활 영역과 체계 해상도를 가진 전문 항목으로
등록하고, 부록은 해당 항목 ID를 연결해 상세히 풀어 쓴다. 후속 통합이 중요한 결론을
놓치지 않게 한다. 부록에는 별도의 `S-`, `Z-`, `N-` 항목 제목을 만들지 않는다.

각 주제는 `### 1. 주제` 형식 아래 `연결 항목:`과 `추가 설명:`으로 작성한다.
기존 전문 항목이나 본문 전체를 반복하지 않으며 다른 체계와 창작 소재를 추가하지 않는다.

### 전문 해석 모드

- `light`: 모든 출력 요소와 일곱 생활 질문을 간결하게 다룬다. 관련 근거를 묶어
  7~10개의 충실한 항목을 우선하되, 필요한 근거·해석을 누락하며 개수를 맞추지 않는다.
- `deep`: 모든 출력 요소와 상호작용을 깊이 다룬다. 각 생활 질문에 대해 대안적 발현,
  강점의 성립 조건, 취약점, 마찰과 시간에 따른 변화를 근거 범위에서 설명한다.
  내부 사고 과정이나 폐기한 초안은 출력하지 않는다.
