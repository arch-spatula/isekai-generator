# 네이탈 차트 해석 과제와 출력 템플릿

지정된 차트 보고서의 네이탈 부분과 해당 evidence만 사용해 아래 질문에 답한다.
[공통 해석 기준](interpretation-guidelines.md)의 전문 해석 규칙과 선택된 모드를 적용한다.
심리 기능, 삶의 영역, 내적 역동을 서로 구분하면서 하나의 생활 해석으로 연결한다.

앵글·하우스·행성·별자리·역행·애스펙트를 먼저 해석하고, 그 결과를 생활 영역으로 종합한 뒤
이 사람에게 추가로 설명할 내용을 부록에 붙인다.

## 작성 방법

- 아래 Markdown의 장 제목과 순서를 그대로 사용하고 각 장을 한 번씩 작성한다.
- 대괄호 안의 질문을 실제 근거에 기반한 답으로 교체한다. 질문·대괄호·작성 지침은 결과에 남기지 않는다.
- `관찰:`에는 계산된 사실, `해석:`에는 그 사실의 상호작용과 생활에서의 발현을 쓴다.
- 행성은 기능, 별자리는 표현 방식, 하우스·앵글은 발현 영역, 애스펙트의 종류·오브는
  기능 사이의 관계로 읽는다. 개별 배치를 보존하면서 반복되는 구성을 연결한다.
- 출력되지 않은 DESC·IC·포인트·하우스·애스펙트를 새 계산 결과로 보충하지 않는다.
  `Angles`, `Houses`, `Chiron`, `Fortuna`가 없으면 관련 장에서 부재를 명시한다.
- 전문 항목에는 앞선 고유 해석을 바탕으로 공통 기준의 일곱 생활 질문에 답한다. `해상도:`는
  `심리 기능`, `삶의 영역`, `내적 역동`만 사용하며 세 라벨을 모두 최소 한 번 포함한다.

## 출력 템플릿

```markdown
# 네이탈 차트 심층 해석

## 계산 전제

관찰: [황도대·관측 위치·월교점·시간 환산·실제 하우스 시스템·경계 포함 규칙은 무엇인가? 어떤 조건부 자료와 계산된 시기 자료가 있는가?]
해석: [이 계산 범위에서 어떤 심리·생활·시간 층위를 읽을 수 있는가? 없는 자료는 무엇인가?]

## 앵글과 하우스

관찰: [출력된 모든 앵글과 하우스 커스프의 별자리·도수는 무엇인가? 시간 의존 자료가 없다면 무엇이 없는가?]
해석: [출력된 각 앵글과 열두 하우스의 조건은 해당 기능과 발현 영역을 어떻게 설명하는가? 하우스 자료가 없을 때는 출력된 근거로 어떤 발현 영역을 설명할 수 있는가?]

## 행성 배치

### 각 기능과 표현 방식

관찰: [출력된 모든 행성·노드·파생 포인트 각각의 별자리·도수·역행 여부·하우스는 무엇인가? 키론·포르투나 등 조건부 포인트 중 없는 것은 무엇인가?]
해석: [각 행성의 기능은 별자리의 표현 방식·역행 상태·하우스의 영역과 결합해 어떻게 작동하는가? 각 노드·포인트는 보고서의 배치에서 무엇을 더 설명하는가?]

### 배치의 반복과 차이

관찰: [여러 기능이 같은 별자리나 하우스에 모이거나 다른 영역으로 나뉘는 배치는 무엇인가?]
해석: [개별 배치를 함께 읽을 때 어떤 기능이 서로를 지원하거나 경쟁하는가? 별자리의 공통점과 하우스의 차이는 발현을 어떻게 바꾸는가?]

## 주요 애스펙트

관찰: [출력된 모든 주요 애스펙트의 두 대상·종류·오브는 무엇인가?]
해석: [출력된 애스펙트 각각은 어떤 강화·긴장·보상·투사를 만드는가? 종류와 오브의 차이, 같은 기능에 모이는 여러 연결은 어떤 행동과 갈등·성장 조건으로 이어지는가?]

## 차트 내부 종합

관찰: [행성·별자리·하우스·앵글·애스펙트에서 실제로 반복되거나 함께 연결되는 구성은 무엇인가?]
해석: [서로 다른 욕구와 기능은 어떻게 협력하거나 충돌하는가? 내적 동기·행동·환경 반응의 반복 패턴은 무엇이며 어떤 조건에서 다른 발현으로 바뀌는가?]

## 전문 해석 항목

[앞선 앵글·하우스·행성·별자리·역행·애스펙트 해석을 근거로 일곱 생활 영역을 종합한다.]

### N-01
영역: [공통 기준의 정확한 생활 영역 라벨]
해상도: [심리 기능·삶의 영역·내적 역동 중 하나]
해석: [앞선 어떤 요소들의 해석을 종합했는지 밝히고, 해당 생활 질문에 결론부터 답한 뒤 실제 행동·강점·취약점·발현 조건을 설명한다.]
근거: [이 항목을 지지하는 실제 N-E evidence ID]

[N-02부터 필요한 전문 항목을 모두 작성한 뒤 부록으로 넘어간다.]

## 개인별 부록

### 1. [이 사람에게 추가 설명이 필요한 주제]
연결 항목: [앞서 등록한 실제 N- 항목 ID]
추가 설명: [일반적인 생활 영역 요약만으로 부족한 특이 조합·상반된 발현·시기 조건은 무엇이며 왜 이 사람에게 중요한가?]
```

`N-02`부터 같은 형식으로 필요한 항목을 이어 쓴다. 근거가 다른 결론은 항목을 나누고,
모든 네이탈 evidence ID가 전문 항목들의 `근거:`에서 최소 한 번 사용되게 한다.
시기운 질문에는 실제로 계산된 시간 층위만 사용한다. 트랜짓·진행·솔라 리턴 등의 자료가
없으면 그 부재를 명시하고 네이탈의 정적 경향과 발현 조건으로 답한다.
부록은 공통 기준에 따라 필요한 주제만 작성하고, 추가 설명이 없으면 그 사실만 표시한다.
