# 공통 게임 화면·아트 계약

개인화 전투·세계 선택 및 GDD 생성은 이 문서를 공통 제작 조건으로 읽는다.
light/deep과 독립 호출에 같은 조건을 적용한다. 모든 후보가 이 범위 안에서 성립해야 한다.
차트·전문 해석·통합 해석의 의미를 이 스타일에 맞추어 바꾸지 않는다.

## 고정 조건과 출력 선언

전투 브리프, 세계 브리프, GDD에는 아래 블록을 문서 끝에 정확히 한 번 복사한다.
개인 해석 ID를 공통 조건의 근거로 붙이지 않는다. 전투·세계 지문의 축에는 추가하지 않는다.

```game-presentation
{
  "schemaVersion": 1,
  "dimension": "2d",
  "view": "top-down",
  "artStyle": "pixel-art",
  "productionScale": "indie",
  "settingGenre": "otherworld-fantasy",
  "gameGenre": "action-rpg"
}
```

## 화면과 아트

세피리아를 참고한 2D 탑다운 픽셀 액션의 화면·조작 감각을 공통 기준으로 삼는다.
고정된 관찰 각도에서 바닥과 인물의 앞·옆면을 함께 읽으며 바닥 평면의 상하좌우로
이동·조준한다. 횡스크롤·벨트스크롤·별도의 등각 투영 플레이로 바꾸거나 자유 회전·
어깨 너머 카메라와 원근 깊이 방향의 자유 3D 조준을 요구하지 않는다.

작고 단순화된 인물 비례, 뚜렷한 실루엣, 일관된 픽셀 밀도를 사용한다. 캐릭터·적·
플레이 배경·전투 효과는 픽셀아트로 설계하며 팔레트·의상·종족·지역 분위기는 개인화한다.
회화적 배경과 픽셀 캐릭터를 섞는 매체를 기본값으로 선택하지 않는다. UI 글꼴까지
모두 픽셀로 제한하지 않으며 대화 초상화의 매체는 아직 확정하지 않는다.

수직 도시·공중전·등반·층 전환은 탑다운 평면의 연결 지점과 명시적 층 규칙으로 설명한다.
점프·부유를 사용할 때는 그림자·착지 표시·높이 판정을 명시한다. 장식적 높이나 가림이
숨은 3D 조준을 요구해서는 안 된다. 패럴랙스·화면 흔들림·확대·축소는 허용한다.

## 액션과 성장

이동·주 공격·방어 대응을 중심으로 빠르고 직관적인 반응과 즉각적인 피드백을 설계한다.
회피·막기·받아치기 중 원형에 맞는 대응을 선택하며 모두 같은 방어 기술을 요구하지 않는다.
공격 준비·유효 범위·명중 결과를 짧은 동작, 형태, 대비와 소리로 구별한다. 다수의 적과
효과가 겹쳐도 작은 플레이어, 적의 전조, 보스와 안전한 이동 공간이 읽혀야 한다.

전투 원형, 힘의 매체, 고유 동사와 리듬은 개인화한다. 원거리·설치·소환도 허용한다.
아이템·능력의 획득과 조합은 공격 범위·궤적·연계·발동 조건·위치 선택·자원 운용 중
실제 전투 결정을 바꾸며 그 변화를 화면에서 구별할 수 있어야 한다. 탐험 중 교류와
귀환은 전투 사이의 호흡으로 설계하고 핵심 액션을 대체하지 않는다.

인디 규모에서 먼저 구현할 핵심 조우와 재사용할 규칙을 선택한다. 원작의 콘텐츠 수를
제작 목표로 삼지 않는다. 해상도·스프라이트 규격·카메라 각도 수치는 아직 고정하지 않는다.
세피리아의 탑 하강·토끼·무기 목록·석판 인접 배치·사망 초기화·랜덤 방·온라인 협동은
필수가 아니다. 로그라이트 진행과 대화 일러스트 스타일은 별도 결정이다.

## 단계별 설계와 의미 검토

- 전투 선택: 모든 후보의 기존 `core-loop`와 `growth-path`에 탑다운 조작·범위·대응과
  성장에 따른 선택 변화를 설명한다. 후보를 점수로 선택하기 전에 화면·매체·조작의
  충돌과 가독성·제작 범위를 검토한다. 부적합 후보는 기존 수정 한도 안에서 수정한다.
- 세계 선택: 모든 후보의 `spatialPlay`와 `verbMapping`에 연결·해금·귀환·높이·가림을
  같은 화면 문법으로 표현한다. 세계 지형과 이동 축은 유지하고 시점으로 다양성을 대신하지 않는다.
- GDD: 이동 평면, 타격·높이 판정, 가림 처리, 픽셀 실루엣·전조, 구현 우선 조우를
  설명한다. 기본 공격·방어의 피드백, 다수 적과 보스의 가독성, 빌드 성장 전후의 선택
  변화 사례를 각각 포함한다. 색과 분위기만으로 픽셀아트 설계를 대신하지 않는다.

출력 전 선언과 본문이 일치하는지 검토한다. `2D`라는 선언 뒤 어깨 너머 자유 조준을
설계하거나 전조를 덮는 효과를 정당화하지 않는다. 자연어 충돌이 해결되지 않으면 실패를
반환하며 검증기 통과를 의미 검토 통과로 대신하지 않는다. 수정은 해당 단계의 기존
1회 한도를 따르고 최종 검증은 유효한 단계를 임의로 재작성하지 않는다.

검증기는 선언의 형식·고정 값·단계 간 일치를 검사한다. 자연어 조작성·가독성·제작 가능성은
생성 에이전트와 수용 검토의 책임이다. 검토 예시는
[공통 화면·아트 spec](../spec/game-presentation-contract.md)의 수용 사례를 따른다.
