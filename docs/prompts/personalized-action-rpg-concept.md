# GDD 작성 지침

이 문서는 실제 출력 템플릿이다. `chart-interpretation.md`를 설계의 주 입력으로 사용하고,
`chart-report.md`는 근거 확인에만 사용한다. 원시 차트를 다시 해석하거나 입력을 요구하지 않는다.
`gameplay-concept-brief.md`, `world-concept-brief.md`의 선정 계약과
[공통 게임 화면·아트 계약](game-presentation-contract.md)을 함께 읽는다.

출력은 아래 경계 안의 H1과 H2를 문구·순서 그대로 사용한다. 경계 주석과 이 작성 지침은
출력하지 않는다. H1은 한 개, H2는 아래 열한 개만 허용하며 각 절을 실제 내용으로 채운다.
게임명은 1절 본문에 작성한다. H3 이하 소제목·표·목록은 필요에 따라 사용한다.
각 절의 안내 문장은 완성된 기획 내용으로 바꾸고 빈 절을 남기지 않는다.
`light`는 각 절을 간결하게, `deep`은 같은 구조 안에서 인과와 사례를 깊게 설명한다.

중요 개인화 선택 뒤에는 `설계 모티프: <구체적 모티프>`와
`해석 근거: <실존하는 I-XX ID 목록>`을 함께 붙인다. 직업·문서·관리 절차의 표면 명사를
그대로 마법으로 바꾸지 말고 동기·갈등·판단 방식·성장 경로를 액션과 세계로 번역한다.
공통 제작 조건에는 해석 ID를 붙이지 않는다. 원본 보고서·해석·브리프를 통째로 첨부하지 않는다.

# 개인화 액션 RPG 기획서

## 1. 게임 개요

게임명, 한 문장 소개, 장르, 핵심 플레이어 판타지와 게임을 관통하는 설계 중심축을 제시한다.
공통 화면·아트 조건이 이 게임에서 어떻게 보이는지 설명한다.

## 2. 플레이어 경험과 핵심 재미

플레이어의 주요 행동, 반복 플레이 루프, 판단과 보상, 이 게임만의 재미를 구체화한다.

## 3. 주인공과 주요 인물

주인공의 욕망·갈등·약점과 주요 인물의 역할·욕망·관계, 플레이에 미치는 영향을 설명한다.

## 4. 세계와 주요 지역

선정된 세계의 위상·생태·이동·정착·위험·공간 논리를 유지한다. 이름 있는 주요 지역,
연결 경로, 탐험 관문과 귀환 경로를 설계하고 전투 동작이 각 공간에서 어떻게 작동하는지 설명한다.

## 5. 전투 시스템

선정된 전투 판타지·축·주요 동사·핵심 루프·성장 경로·약점을 유지한다. 조작, 거리와 위치,
적의 대응, 공격·방어·전환의 판단을 실제 전투 흐름으로 보여 준다. 화면·카메라 조건을 반영한다.

## 6. 능력의 기원과 성장

능력의 기원, 최초 발현, 초기 가능 범위와 한계, 숙련, 확장 사건, 후반 위력, 대가와 위험,
적과 세계의 대응을 인과적으로 연결한다. 전투 능력 상승과 인격·관계 성장을 구별한다.

## 7. 탐험과 게임 진행

지역 이동, 탐험 관문, 전투·탐험 보상과 성장의 순환, 재방문, 캠페인 진행을 구체화한다.

## 8. 서사와 인물 관계의 변화

주요 사건과 선택이 갈등·인물 관계·세계 반응을 어떻게 바꾸는지 보여 준다.
초반부터 결말까지의 변화와 플레이 행동의 연결을 설명한다.

## 9. 대표 플레이 시나리오

구체적인 장소에서 탐험·조우·전투 판단·능력 사용·보상·관계 또는 세계 반응으로 이어지는
대표 플레이를 순서대로 보여 준다. 앞 절의 규칙과 성장 단계, 화면 조건을 지킨다.

## 10. 개인화 설계 근거

주요 설계 선택과 해석 항목의 연결을 요약한다. 모티프와 실존 ID를 함께 제시하고,
여러 해석 영역의 긴장과 동기·판단·성장이 어떤 게임 경험으로 번역되었는지 설명한다.

## 11. 구조화된 설계 선언

선정 브리프의 최종 일곱 축 키와 값을 그대로 복사한 `combat-fingerprint` JSON fenced block을
정확히 한 번 작성한다. 추가 키를 넣지 않는다.
`world-structure` JSON fenced block도 정확히 한 번 작성한다. 키는 `topology`, `ecology`,
`traversal`, `settlement`, `hazard`, `spatialLogic`이며 각 값은 정확히 `value`와
`manifestation`을 가진 객체다. `value`는 선정 세계 fingerprint 값, `manifestation`은
본문에 구현한 구체적인 공간·연결·이동·위험·귀환 방식이다.
마지막에 공통 계약의 `game-presentation` block을 정확히 한 번 그대로 복사한다.
선언과 본문의 전투·세계·조작·카메라·아트가 일치하는지 의미 검토한다.
