# 자미두수 해석 과제와 출력 템플릿

지정된 차트 보고서의 자미두수 부분과 해당 evidence만 사용해 아래 질문에 답한다.
[공통 해석 기준](interpretation-guidelines.md)의 전문 해석 규칙과 선택된 모드를 적용한다.
궁위 역할, 성요 상태, 시간 층위를 서로 구분하면서 하나의 생활 해석으로 연결한다.

명궁·신궁·열두 궁·성요의 분류와 밝기·사화·시기를 먼저 해석하고, 그 결과를 생활 영역으로 종합한 뒤
이 사람에게 추가로 설명할 내용을 부록에 붙인다.

## 작성 방법

- 아래 Markdown의 장 제목과 순서를 그대로 사용하고 각 장을 한 번씩 작성한다.
- 대괄호 안의 질문을 실제 근거에 기반한 답으로 교체한다. 질문·대괄호·작성 지침은 결과에 남기지 않는다.
- `관찰:`에는 계산된 사실, `해석:`에는 그 사실의 상호작용과 생활에서의 발현을 쓴다.
- 열두 궁을 각각의 성격 한 문장으로 축약하지 않는다. 주성·보조성·밝기·사화·살성군의 조합이
  권한·의존·끌림·갈등·지원·반전에 어떤 차이를 만드는지 설명한다.
- 출력되지 않은 성계나 궁 사이의 관계를 새 계산 결과로 보충하지 않는다.
- 전문 항목에는 앞선 고유 해석을 바탕으로 공통 기준의 일곱 생활 질문에 답한다. `해상도:`는
  `궁위 역할`, `성요 상태`, `시간 층위`만 사용하며 세 라벨을 모두 최소 한 번 포함한다.

## 출력 템플릿

```markdown
# 자미두수 심층 해석

## 계산 전제

관찰: [달력·연주·유년 경계, 시각 보정, 자시·윤월 처리, 대한·유년 나이는 어떤 기준으로 계산됐는가?]
해석: [이 기준에 따라 본명·대한·유년·유월의 시점을 어떻게 구별해야 하는가?]

## 명반 기본 구조

관찰: [연주, 명궁, 신궁, 오행국과 대한 시작점은 무엇인가? 명궁과 신궁에는 어떤 성요와 상태가 있는가?]
해석: [자기 정체성과 실제 몰입·행동의 중심은 어떻게 연결되거나 긴장하는가? 이 배치가 다른 생활 영역을 읽는 데 어떤 중심을 제공하는가?]

## 십이궁과 성요

### 성요의 분류와 상태

관찰: [출력된 주성·보조성·살성군은 어떻게 구분되며, 각 성요의 廟·旺·得·平·陷 등 밝기와 사화는 무엇인가?]
해석: [성요의 역할과 밝기·사화의 차이는 궁에서의 발현을 어떻게 바꾸는가? 같은 밝기라도 성요와 궁의 조합에 따라 무엇이 달라지는가?]

### 열두 궁의 개별 해석

| 궁 | 관찰 | 해석할 질문에 대한 답 |
| --- | --- | --- |
| 명궁 | [간지·신궁 여부·주성 또는 공궁·밝기·사화·보조성·살성군] | [이 조합은 자기 정체성과 기본적인 선택 방식에 어떻게 작용하는가?] |
| 형제궁 | [동일한 관찰 항목] | [가까운 동등 관계의 지원·경쟁·거리는 어떻게 나타나는가?] |
| 부처궁 | [동일한 관찰 항목] | [친밀한 결합의 끌림·협력·마찰은 어떤 구조를 가지는가?] |
| 자녀궁 | [동일한 관찰 항목] | [자녀 및 양육·돌봄의 관계에서 어떤 작용이 나타나는가?] |
| 재백궁 | [동일한 관찰 항목] | [자원을 얻고 운용하는 방식에는 어떤 작용이 나타나는가?] |
| 질액궁 | [동일한 관찰 항목] | [몸의 부담과 생활 리듬은 어떤 조건에서 드러나는가?] |
| 천이궁 | [동일한 관찰 항목] | [외부 환경과 이동에서 어떤 기회·압력·반응이 나타나는가?] |
| 교우궁 | [동일한 관찰 항목] | [사회적 협력과 주변 사람의 도움·부담은 어떻게 나타나는가?] |
| 관록궁 | [동일한 관찰 항목] | [사회적 역할과 일의 수행에는 어떤 방식과 마찰이 나타나는가?] |
| 전택궁 | [동일한 관찰 항목] | [거주와 생활 기반의 유지·변화에는 어떤 작용이 나타나는가?] |
| 복덕궁 | [동일한 관찰 항목] | [내적 만족과 휴식·정서적 회복은 어떤 방식으로 나타나는가?] |
| 부모궁 | [동일한 관찰 항목] | [부모·연장자와의 지원·기대·거리는 어떻게 나타나는가?] |

관찰: [보고서가 제공한 궁위 사이의 연결과 신궁 위치는 무엇인가?]
해석: [개별 궁 해석을 함께 읽을 때 어느 궁의 조건이 다른 궁의 발현을 지원하거나 어렵게 하는가?]

## 본명 사화

관찰: [化祿·化權·化科·化忌는 각각 어느 성요와 궁에 놓이는가?]
해석: [네 사화는 자원·영향력·평가·집착 또는 부담을 어떤 생활 영역에 배분하는가? 성요 상태와 결합하면 기회와 갈등의 방향은 어떻게 달라지는가?]

## 대한

관찰: [출력된 모든 대한의 나이 범위·궁·성요는 무엇인가?]
해석: [각 대한에서 본명의 어떤 과제가 중심으로 이동하는가? 이전 대한과 비교해 선택·관계·환경의 요구가 어떻게 바뀌는가?]

## 유년과 유월

관찰: [조회 유년의 기간·나이·명궁과 본명 궁 대응, 모든 유년 사화·궁 매핑, 열두 유월의 명궁 위치와 본명 궁 대응은 무엇인가?]
해석: [대한이라는 배경에서 유년의 초점은 무엇이며, 각 유월은 그 초점을 어떤 생활 영역으로 옮기는가? 본명 성향과 대한·유년·유월의 의미를 구분하면 각 층위에서 무엇을 말할 수 있는가?]

## 전문 해석 항목

[앞선 명궁·신궁·열두 궁·성요의 분류와 밝기·사화·시기 해석을 근거로 일곱 생활 영역을 종합한다.]

### Z-01
영역: [공통 기준의 정확한 생활 영역 라벨]
해상도: [궁위 역할·성요 상태·시간 층위 중 하나]
해석: [앞선 어떤 요소들의 해석을 종합했는지 밝히고, 해당 생활 질문에 결론부터 답한 뒤 실제 행동·강점·취약점·발현 조건을 설명한다. 시기를 다룰 때 어느 시간 층위인지 밝힌다.]
근거: [이 항목을 지지하는 실제 Z-E evidence ID]

[Z-02부터 필요한 전문 항목을 모두 작성한 뒤 부록으로 넘어간다.]

## 개인별 부록

### 1. [이 사람에게 추가 설명이 필요한 주제]
연결 항목: [앞서 등록한 실제 Z- 항목 ID]
추가 설명: [일반적인 생활 영역 요약만으로 부족한 특이 조합·상반된 발현·시기 조건은 무엇이며 왜 이 사람에게 중요한가?]
```

`Z-02`부터 같은 형식으로 필요한 항목을 이어 쓴다. 근거가 다른 결론은 항목을 나누고,
모든 자미두수 evidence ID가 전문 항목들의 `근거:`에서 최소 한 번 사용되게 한다.
시기 자료가 없으면 해당 장에서 부재를 설명하고, 본명의 정적 성향으로 답할 수 있는 범위를 쓴다.
부록은 공통 기준에 따라 필요한 주제만 작성하고, 추가 설명이 없으면 그 사실만 표시한다.
