# 자미두수 1차 판단 문서와 검증기

> 상태: 구현 완료 — 검증기(`scripts/check-ziwei-judgment.ts`)와 작성 스킬(`.claude/skills/ziwei-judgment`)
> 작성일: 2026-11-19

## 1. 목표

자미두수 전문 해석 에이전트가 상세 해석 전에 모두 따라야 하는 기초 판단을 한 문서로 고정한다.
형식·근거 인용·대안 규칙은 [사주 1차 판단](saju-first-pass-judgment.md) §2·§5와 같고, 이 문서는 자미두수에서
달라지는 것만 정한다.

- 입력: 같은 차트 디렉터리의 `ziwei-chart.md`, `ziwei-facts.md`만 읽는다.
- 출력: 같은 디렉터리의 `ziwei-judgment.md`. 이미 있으면 덮어쓰지 않는다.

자미두수에는 사주의 용신처럼 하나로 모이는 판단이 없다. 그래서 상세 해석끼리 어긋나기 쉬운 지점을 고정한다.

## 2. 문서 형식

가상 예제:

```markdown
# 紫微斗數 1차 판단

명반: 命宮 乙酉 · 身宮 夫妻 (未) · 水二局

## 명궁 역량
결론: 약
근거: [facts:명궁 주성] [facts:삼방사정 보조성 수]
대안: 중 — [facts:명궁 삼방사정] …
뒤집힘: …

## 격국
…

## 강점 궁
…

## 과제 궁
…
```

| 섹션 | 결론 허용값 | 고정하는 이유 |
| --- | --- | --- |
| 명궁 역량 | 강 · 중 · 약 | 주성 묘왕리함과 삼방사정 길성·煞성 균형이 해석 전체의 톤을 정한다 |
| 격국 | 자유 텍스트 | 격 이름과 성격·파격 여부. 사주 §4.1과 같은 보류 정책을 따른다 |
| 강점 궁 | 12궁 이름 | 化祿·길성이 모인 궁을 해석마다 다르게 짚지 않게 한다 |
| 과제 궁 | 12궁 이름 | 化忌·煞성이 모인 궁. 강점 궁과 달라야 한다 |

- `명반` 줄은 `ziwei-chart.md` 머리의 `命宮`, `身宮`, `五行局` 값을 `命宮 <간지> · 身宮 <궁 (지지)> · <오행국>`으로 쓴다.
- 12궁 이름은 `命宮 · 兄弟 · 夫妻 · 子女 · 財帛 · 疾厄 · 遷移 · 交友 · 官祿 · 田宅 · 福德 · 父母`이며 접미사(`宮`)를 붙이지 않는다.
- `[chart:…]`로 인용할 수 있는 것은 절 제목(`紫微斗數 命盤`, `十二宮`, `四化`)과 12궁 이름이다.
- 사주의 `기준` 같은 섹션 전용 필드는 없다.

## 3. 본명반만 다룬다

`流年`·`流月`은 `--flow-year`(기본값 올해)에 따라 바뀌어 같은 명반의 1차 판단이 해마다 달라질 수 있다. `大限`은
고정값이지만 시기 해석이라 기초 판단 다음 단계에 맡긴다. 세 절은 인용하면 검증 실패다.

## 4. 근거가 되는 사실 층

판단 항목에 맞춰 `ziwei-facts.md`에 규칙 계산 항목을 둔다. 판단 결론은 쓰지 않는다.

- 명궁 주성(空宮이면 대궁 차성), 신궁, 오행국, 명궁 삼방사정과 보조성 수
- `殺破狼`·`機月同梁`: 해당 주성이 모두 명궁 삼방사정에 있는지. 성격·파격은 판단에 남긴다
- `궁별 보조성 수`: 12궁마다 吉·煞 수와 생년사화
- `생년사화 위치`, `化忌 충`(생년 化忌 궁의 대궁)

## 5. 검증기

`scripts/check-ziwei-judgment.ts <차트 디렉터리>`. 사주와 같은 공통 검사(`scripts/judgment-document.ts`)에
위 설정을 넘기고, 추가로 다음을 본다.

| 검사 | 막는 실수 |
| --- | --- |
| `명반`이 차트 머리와 일치한다 | 다른 디렉터리·다른 명반 참조 |
| 강점 궁·과제 궁이 12궁 이름이다 | `官祿宮` 같은 표기 흔들림 |
| 강점 궁과 과제 궁이 다르다 | 자기모순 |
| `流年`·`流月`·`大限`을 인용하지 않는다 | 조회 연도에 따라 흔들리는 기초 판단 |

테스트는 커밋된 합성 fixture(`scripts/fixtures/ziwei-judgment/`)와 그 변형으로 한다
(`bun test scripts/check-ziwei-judgment.test.ts`). 공통 규칙은 사주 검증기 테스트가 함께 지킨다.
