# 능력 규칙의 구체성과 캐릭터 이미지 전달력의 불일치

## 상태와 자료 범위

- 발견일: 2026-11-09
- 발견 경위: 세 로컬 GDD를 비교하며 한 사례의 능력이 더 추상적으로 느껴지는지 검토
- 상태: 미해결 — 관찰과 분석 기록, 생성 지침·검증기 변경 없음
- 자료 성격: 아래 사례 A·B·C는 당시 문서의 최소 요약이다. 원본 GDD와 출생정보는 포함하지 않는다.

## 증상

사례 A는 방어 성공 조건, 자원 상한, 방출 선택과 성장 규칙이 상세하지만 능력의
첫인상을 설명하는 명칭과 시각적 대상은 사례 B·C보다 여러 설명을 연결해야 이해된다.
규칙을 구체적으로 작성한 것만으로 캐릭터의 능력이 쉽게 떠오른다고 볼 수 없다.

| 비교 항목 | 사례 A | 사례 B | 사례 C |
| --- | --- | --- | --- |
| 능력의 중심 대상 | 공명, 주문 막, 방출 호 | 자신을 닮은 잔영 | 던지고 돌아오는 회전날 |
| 핵심 행동 | 막기 → 저장 → 좁거나 넓게 방출 | 지시 → 추격 → 회수 | 막기 → 충전 → 투척·회수 |
| 자원과 위험 | 방어 성공당 1칸, 최대 2칸, 연속 사용 시 과열 | 잔영 파괴 시 소환 공백 | 막기 실패 시 체력 손실, 무기 귀환 중 빈틈 |
| 성장 후 선택 | 즉시 직선 관통 또는 두 칸을 모아 옆 퇴로를 여는 원호 | 먼 적 추격 또는 가까운 위협에 잔영 유지 | 회수 위치와 곡선을 바꿔 여러 적 적중 |

사례 A에는 바라보는 방향의 짧은 막으로 공격을 받아 자원을 얻고, 이동과 기본 공격으로
열을 식히는 규칙도 있다. 따라서 관찰된 문제를 능력의 작동 규칙 부재나 성장 부재로
분류하지 않는다. 오히려 자원·실패·성장 조건은 세 사례 중 더 상세하게 서술돼 있다.

## 기대 결과와 영향

능력의 최초 소개만 읽어도 무엇을 사용하는 캐릭터인지, 어떤 형태와 동작으로 힘이
나타나는지 이해할 수 있어야 한다. 뒤의 상세 규칙은 그 이미지를 확장해야 한다.

- 캐릭터 소개에서 긴 규칙 설명을 읽기 전에는 대표 장면을 떠올리기 어려울 수 있다.
- 컨셉아트 제작자가 중심 대상과 실루엣을 추가로 창작해야 하는 여지가 커질 수 있다.
- 구조 검증이나 상세한 자원 설명만으로는 이러한 전달 문제를 구별하기 어렵다.

## 분석과 한계

확인한 사실은 세 문서의 표현과 규칙 구성 차이다. 사례 A는 보이지 않는 자원인
공명과 낯선 능력 명칭, 막과 여러 방출 형태를 함께 설명한다. 세계 설명의 생기·순환·
사용 몫도 독자가 연결해야 하는 개념을 늘린다. 사례 B·C는 잔영이나 회전날처럼
행동의 주체 또는 매개체가 바로 드러난다.

이 차이가 사례 A의 첫인상을 더 추상적으로 만드는 것으로 판단한다. 다만 추상성의
원인을 각 요소별로 분리한 실험, 독자 이해도 측정, 동일 조건의 컨셉아트 비교는
수행하지 않았다. 특정 생성 지침이나 모델 동작이 원인이라고 확정하지 않는다.
주문이나 보이지 않는 자원 자체를 결함으로 보거나 무기 중심 설계를 우수하다고
일반화하지 않는다. 사례 A에도 막 테두리와 방출 형태의 시각 설명은 존재한다.

원본은 로컬 생성 결과이므로 원본 없는 환경에서 당시 문구와 비교 판단을 독립적으로
재검증하는 데 한계가 있다. 위 요약은 자동 재현 테스트나 독자 평가 결과가 아니다.

## 후속 검토와 수용 기준

1. 능력의 최초 소개와 대표 장면에서 중심 대상, 형태, 행동과 결과가 연결되는지 검토한다.
2. 규칙의 구체성과 이미지 전달력을 별도로 평가한다. 설명 길이나 고유명사 수를 품질 점수로 대리하지 않는다.
3. 추상 자원을 사용하는 능력도 일관된 형상·동작으로 전달되는 합성 사례를 마련해 비교한다.
4. 이미지 전달을 개선하더라도 자원 획득 조건, 실패 위험과 성장 후 선택을 보존하는지 확인한다.
5. 자동 검사를 추가한다면 선언의 존재와 독자의 실제 이해도를 구별한다. 필드 충족만으로 시각적 명료성이 검증됐다고 주장하지 않는다.

이번 기록은 문서 비교에서 확인한 문제를 보존한다. 기존 아티팩트 수정, 능력 재설계,
새 이미지 생성, 생성 파이프라인 변경과 자동 회귀 테스트 추가는 수행하지 않았다.
