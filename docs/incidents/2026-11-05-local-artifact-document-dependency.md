# 영구 문서의 로컬 아티팩트 의존

## 상태

- 상태: 해결 — 문서 정비·참조 검사·아티팩트 없는 사본 검증 완료.
- 발견일: 2026-11-05.
- 해결 계획: [로컬 아티팩트와 영구 문서의 근거 분리](../spec/local-artifact-document-boundary.md).
- 범위: 저장소에서 관리하는 문서·프롬프트·스킬의 근거, 비교 대상과 재현 절차.

## 문제

`artifacts/`는 `.gitignore`로 제외된 로컬 생성 결과 저장소다. 그러나 커밋되는 문서에서
그 아래 특정 실행 파일을 링크하거나, 특정 실행과의 비교를 검증 조건으로 지정했다.
저장소에 포함되지 않고 보존도 보장되지 않는 자료를 영구적으로 접근할 수 있는 근거처럼
다룬 것이다.

경로 문자열의 문제뿐 아니라 문서의 실행 가능성과 근거 보존 방식의 문제다. 링크를
일반 경로로 바꾸더라도 같은 개인의 이전 출력이나 출생 입력이 있어야 수행할 수 있는
검증 절차가 남으면 해결되지 않는다.

## 정비 전 확인한 사례

| 저장소 문서 | 확인한 의존 | 문제 |
| --- | --- | --- |
| [해석 프롬프트 품질 이슈](2026-11-03-interpretation-prompt-quality.md)의 재발 관찰 근거 | 특정 실행의 사주 문서 링크와 행 번호, 로컬 검증 결과 | 근거의 영구 접근 가능성을 잘못 암시함 |
| [GDD 직역 개선 계획](../GDD/personalized-gdd-remediation-plan.md)의 기준 사례·동일 차트 회귀 | 특정 이전 GDD와 동일 출생 입력을 비교의 전제로 사용 | 로컬 파일과 개인 입력이 없으면 절차를 수행할 수 없음 |
| [해양 세계관 수렴 이슈](2026-11-04-maritime-world-setting-convergence.md)의 조사·회귀 기준 | 실행별 분류표와 과거 결과를 fixture로 보존하라는 지시 | 당시 관찰 기록과 커밋된 재현 자료의 구분이 불명확함 |
| [기준선 채택 기록](../ADR/2026-11-05-adopt-artifact-series-0.2.md)의 확인 근거 | 로컬 생성 성공을 특정 실행 식별자로 설명 | 기록된 관찰과 다른 환경에서 검증 가능한 증거를 구분해야 함 |

위 링크는 문제를 가진 **저장소 문서**를 가리킨다. 이 인시던트의 이해나 해결에 로컬
아티팩트 원본을 읽을 필요는 없다. 이 문서는 실제로 확인한 문서 의존을 기록하며,
다른 사용자가 이미 재현에 실패했다는 사건까지 주장하지 않는다.

## 영향

- 새 clone이나 다른 작업 환경에서는 링크 대상과 비교 기준이 존재하지 않는다.
- 로컬 정리로 원본이 삭제되면 문서의 근거와 절차를 복구하기 어렵다.
- 생성 당시의 관찰을 커밋된 회귀 테스트나 독립적으로 재현 가능한 증거로 오인할 수 있다.
- 후속 에이전트가 문서 지시를 따라 존재하지 않는 실행을 찾거나 내용을 추정할 수 있다.
- 이를 해결하려고 원본을 통째로 커밋하면 로컬 생성 결과와 개인 정보의 경계를 훼손한다.

## 원인

- 로컬 작업 중 즉시 확인할 수 있다는 사실과 저장소에서 지속적으로 제공된다는 사실을 혼동했다.
- 인시던트를 작성할 때 경로·행 번호만으로 근거가 보존된다고 취급했다.
- 역사적 관찰, 재현 가능한 fixture, 실행 절차, 경로 예제에 같은 버전 표기를 사용했다.
- 로컬 아티팩트가 없는 환경에서 문서와 회귀 절차를 점검하는 기준이 없었다.

## 해결 원칙

커밋되는 문서는 로컬 아티팩트가 없어도 문제·결정·검증 방법을 이해할 수 있어야 한다.

- 저장 계약은 `artifacts/<version>/...` 같은 일반 경로로 설명한다.
- 문제를 설명하는 데 필요한 최소 사례와 관찰 결과는 개인 정보를 제거해 문서 안에 남긴다.
- 자동 재현은 커밋된 합성 fixture와 실행 가능한 명령을 사용한다.
- 특정 실행의 상세 비교·진행 기록은 해당 로컬 run에 남긴다.
- 과거 관찰은 당시의 관찰임을 밝히고 원본의 영구 보존·독립 재검증 가능성을 주장하지 않는다.
- 원본 전체 커밋, ignore 해제, 외부 업로드를 해결책으로 사용하지 않는다.

## 완료 판정

해결 spec의 문서 분류·정비·fixture·검증·운영 지침 작업을 완료하고, 로컬 아티팩트가
없는 작업 사본에서 문서의 링크와 재현 절차를 확인한 뒤 닫는다. 링크 삭제나 버전 번호의
일괄 치환만으로 해결 완료로 판정하지 않는다.

## 해결 결과

- 로컬 파일 링크와 특정 과거 GDD·개인 입력에 의존하던 회귀 절차를 정비했다.
- 당시 관찰과 집계는 원본의 독립 재검증 한계를 명시해 보존했다.
- 최소 합성 품질 평가 사례와 기존 구조 테스트를 연결했다. 의미 판정은 여전히 별도 과제다.
- 문서 검사와 프로젝트·스킬 작성 지침을 추가하고 기본 테스트 명령에 연결했다.
- 일반 작업 트리와 아티팩트 없는 소스 사본에서 각각 149개 테스트 및 문서 검사 오류 0개를 확인했다.
- 원본 아티팩트와 개인정보를 커밋하거나 외부로 옮기지 않았다.

참조별 분류·유지 이유와 검증 범위는 [해결 spec의 구현 결과](../spec/local-artifact-document-boundary.md#10-구현-결과와-참조-분류-기록)에 기록했다.
이 문제를 닫는 것이 해석 품질·세계관 수렴·컨텍스트 인계 문제까지 해결했다는 뜻은 아니다.
