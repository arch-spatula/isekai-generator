# 개인화 GDD 전투 원형 수렴 이슈

## 상태

- 발견 버전: v0.1.25 생성 후 v0.1.24와 비교
- 영향 버전: v0.1.24, v0.1.25
- 상태: 원인 분석 완료, 개선안 제안
- 후속 결정: [개인화 전투 원형을 후보 비교로 선택](../ADR/2026-11-03-personalized-combat-archetype-selection.md)

## 요약

서로 다른 출생정보로 생성한 v0.1.24와 v0.1.25가 모두 사슬검을 사용하는 근접
사냥꾼을 주인공으로 선택했다. 두 결과는 세계, 인물, 능력 명칭, 관계와 세부 전투
규칙에서는 달랐지만 전투 거리, 힘의 매개체, 이동 방식과 핵심 전투 루프가 유사했다.

개별 GDD만 보면 각각 성립하지만 여러 사용자에게 서로 다른 삶과 플레이 경험을 제공한다는
개인화 목표에서는 결함이다. 출생정보와 통합 해석이 달라져도 주인공의 직업과 조작 경험이
충분히 구별되지 않을 수 있음을 보여 준다.

## 관찰된 수렴

| 구분 | v0.1.24 | v0.1.25 |
|---|---|---|
| 전투 거리 | 근접 중심 | 근접 중심 |
| 주 무기 | 세 형상으로 변하는 잔흔검·사슬날 | 생체 사슬이 달린 맥쇄검 |
| 이동 | 결속과 지형 활용 | 갈고리 이동과 공중 추격 |
| 기본 루프 | 읽기 → 베기 → 결속·고정 → 해방 | 읽기 → 고정 → 충격 축적 → 파열·해방 |
| 대표 적 | 천수급 거대 생물과 부위 파괴 | 하늘짐승·거수와 부위 파괴 |
| 위험 자원 | 심열 | 맥압 |

이름과 설정만 같은 것은 아니다. 붙들거나 연결하는 근접 무기, 거대 생물의 부위 공략,
압력 자원의 축적과 해방까지 플레이 구조가 겹친다.

## 기대 결과

출생정보가 달라졌다고 모든 경우에 반드시 다른 클래스를 선택해야 하는 것은 아니다.
그러나 통합 해석의 차이가 충분하다면 근접 전사뿐 아니라 원거리 마법사, 소환 지휘자,
설치·영역 제어자, 변신 전투가처럼 전투 거리와 힘의 매개체부터 다른 후보가 실제로
검토되어야 한다.

같은 원형을 다시 선택할 때도 다음을 설명할 수 있어야 한다.

- 현재 해석에 이 원형이 가장 적합한 이유
- 구조적으로 다른 후보가 탈락한 이유
- 기존 결과와 비교했을 때 실제 플레이가 다른 지점

## 조사 결과

### 계산 결과나 과거 산출물 재사용은 원인이 아니다

두 버전은 서로 다른 차트 보고서와 통합 해석으로 생성되었다. v0.1.25 GDD 단계는 격리된
에이전트로 실행되어 v0.1.24 산출물을 입력받지 않았다. 통합 해석 단계 역시 무기, 직업,
전투 규칙 같은 창작 요소를 제안하지 않도록 제한되어 있다.

따라서 이전 GDD를 복사했거나 과거 프롬프트 내용이 대화 기록을 통해 유입된 문제로 보지
않는다.

### 서로 다른 해석이 유사한 상위 긴장으로 압축되었다

두 통합 해석의 세부 항목은 다르지만 GDD 단계에서 사용하기 쉬운 상위 긴장은 유사했다.

- 안정과 변화
- 독립과 연결
- 책임 또는 압력의 누적
- 검토 뒤의 결정적 행동
- 붙들어야 할 것과 바꾸어야 할 것의 구분

동일한 모델과 디자인 지침은 이를 `붙들기 → 축적 → 파열`이라는 응집력 높은 Action RPG
문법으로 번역했다. 사슬검은 붙들기, 연결, 거리 조절, 이동과 파열을 한 무기로 설명하기
쉬워 두 번 모두 선택된 것으로 판단한다.

### 현재 파이프라인에는 전투 원형을 분기하는 기준이 없다

통합 해석에서 GDD로 바로 이동하므로 다음을 비교하는 단계가 없다.

- 근접, 중거리와 원거리 중 어느 거리가 적합한가
- 무기, 주문, 소환체, 설치물과 환경 중 무엇을 힘의 매개체로 삼는가
- 직접 타격, 반격, 지휘, 준비·함정과 변신 중 무엇이 주도 방식인가
- 타이밍, 조준, 배치, 자원 조합과 명령 중 무엇을 숙련의 중심으로 삼는가

GDD 생성기는 하나의 응집된 콘셉트를 만들도록 요구받지만 구조적으로 다른 후보를 먼저
경쟁시키지는 않는다. 그 결과 처음 발견한 익숙하고 설명하기 쉬운 해법이 최종안으로
확장될 수 있다.

## 영향

- 개인화가 세계관과 관계 묘사에는 나타나지만 플레이어 판타지에는 약하게 나타날 수 있다.
- 여러 GDD를 비교할 때 모델의 선호 무기와 전투 루프가 반복되어 생성 시스템의 다양성이
  낮아 보인다.
- 각 결과가 개별적으로 완성도가 높아 단일 문서 검증만으로는 문제를 발견하기 어렵다.
- 파워 기원과 성장 인과가 달라도 조작 경험이 유사하면 사용자에게는 같은 직업의 변형처럼
  느껴질 수 있다.

## 해결 방향

이 이슈를 계기로
[개인화 전투 원형을 후보 비교로 선택](../ADR/2026-11-03-personalized-combat-archetype-selection.md)
ADR을 작성했다. ADR은 다음 방향을 제안한다.

1. 통합 해석과 GDD 사이에 `gameplay-concept-brief` 단계를 추가한다.
2. 게임플레이 성향을 구조화된 축으로 추출한다.
3. 최소 네 개의 구조적으로 다른 전투 후보를 비교한다.
4. 후보 선택과 탈락 이유를 통합 해석 ID에 연결한다.
5. 과거 GDD 전문 대신 작은 콘셉트 지문으로 반복 수렴을 감지한다.
6. 후보 개수, 축 차이와 ID 유효성은 결정적 CLI validator가 검사한다.

해당 ADR은 아직 `Proposed` 상태다. 따라서 이 문서의 작성만으로 파이프라인 문제가
해결된 것으로 보지 않는다.

## 재현 및 회귀 확인 기준

개선 구현 후에는 다음 두 종류의 테스트가 필요하다.

### 동일 입력 반복

같은 출생정보를 반복 생성했을 때 무조건 다른 결과를 요구하지 않는다. 대신 선택 후보와
근거가 안정적이고, 임의의 장르 변경보다 해석 적합성이 우선되는지 확인한다.

### 서로 다른 입력 비교

서로 다른 통합 해석으로 생성할 때 다음을 확인한다.

- 구조적으로 다른 후보가 실제로 생성되었는가
- 최종 선택이 해석의 고유 항목을 사용했는가
- 기존 콘셉트와 지문이 유사하면 재검토가 수행되었는가
- 같은 전투 원형을 선택했다면 그 이유와 플레이 차이가 기록되었는가

단순히 무기 이름이나 세계관 고유명사가 다른 것은 통과 기준으로 인정하지 않는다.
