# ADR: 생성 아티팩트 기준선 0.2 채택

* **Status:** Accepted
* **Date:** 2026-11-05
* **Decision Owners:** Project Owner
* **Scope:** 다음 차트·개인화 GDD 생성부터 활성 artifact series를 `0.2`로 전환

## 배경

전투 선택과 세계 선택 분리, 독립 지문 검증, 전문 해석 실패 보존 및 격리 재시도가
구현되었지만 활성 series는 `0.1`로 남아 있었다. 프로젝트 소유자는 TODO에
`v0.2.x` 전환을 허용했고, 이번 변경을 커밋하면서 다음 아티팩트의 버전 전환을 요청했다.

## 결정

- 현재 구현을 `0.2`의 기준선으로 채택하고 명시적 승격 도구로 활성 series를 갱신한다.
- 구현 및 이 결정을 먼저 커밋한다. 깨끗한 작업 트리에서 그 commit을 기준 revision으로
  사용해 승격한 뒤 설정을 별도 커밋한다.
- 다음 새 생성은 `v0.2.0`부터 예약한다. 이번 승격만으로 생성을 실행하거나 번호를 예약하지 않는다.
- 기존 `v0.1.x`는 이동·복사·재번호 부여하지 않는다. 이어서 완료한 `v0.1.31`도 그대로 둔다.
- 무제한 재시도 플래그와 기존 종료 run의 일반적인 재개 기능은 포함하지 않는다.

## 확인한 근거와 한계

- `bun test ./scripts ./.agents`: 17개 파일의 137개 테스트가 통과했다.
- 전문 해석은 실패 기록 후 동일 체계만 복구하며 생성·수정을 합해 최대 3회 실행한다.
- `v0.1.31`은 기존 자미두수·서양 점성술 결과를 재사용하고 사주를 수정해 완료했다.
  전문 해석 3개, 통합, 전투, 세계, GDD 검증이 모두 통과하고 두 지문 등록도 완료했다.
- 이 실행은 이전 코드에서 시작해 현재 코드로 복구한 사례다. 현재 commit의 깨끗한
  상태에서 처음부터 생성한 기준선 확인 실행으로 간주하지 않는다.
- 여러 대표 입력의 전체 생성·이전 기준선 비교는 아직 완료되지 않았다.
  세계 선택의 결정적 검증은 실제 자연어 품질이나 해양 수렴 재발률 개선을 증명하지 않는다.

기존 버전 관리 ADR/spec은 대표 입력군의 회귀 비교 완료 후 승격하도록 정했다.
이번 결정은 소유자의 명시적 전환 의사에 따라 **0.2의 최초 승격에 한해** 그 검증을
후속 작업으로 남긴 채 현재 구현을 채택한다. 검증 완료를 소급 주장하지 않으며,
향후 minor 승격의 일반 조건과 clean working tree 요건은 유지한다.

## 후속 작업

- 설정 commit 이후 별도 요청으로 `v0.2.0` 기준선 확인 생성을 실행한다.
- 서로 다른 대표 입력으로 전체 GDD 회귀 생성 및 이전 기준선 비교를 수행한다.
- 해양 세계관 수렴 incident는 known issue로 계속 연결하며 회귀 비교 전에는 닫지 않는다.
