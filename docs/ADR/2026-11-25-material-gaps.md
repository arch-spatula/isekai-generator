# ADR: 재료 지도가 드러낸 재료 부족을 정리한다

* **Status:** Superseded by [최소 지시 GDD 에이전트](2026-11-28-minimal-gdd-agent.md)
* **Date:** 2026-11-25
* **Decision Owners:** Project Owner
* **관련:** [한 번 검토](2026-11-25-single-pass-review.md),
  [재능과 기질](2026-11-25-talent-temperament.md), #100, #99, #75

## 배경

재료 지도(`bun run check:pipeline --report`)를 처음 적었을 때 알려진 재료 부족이 네 곳 남아 있었다.

1. **장 사건이 추상적이다.** 일생 해석의 "보편적 생애 사건 언어" 규칙이 사건을 "자기 힘을 드러내는 사건을 겪는다"처럼 흐리게 만들었다. 장별 세계·지역·대표 장면이 이 사건을 재료로 쓴다.
2. **전투가 세계보다 먼저 적을 정한다.** 흐름이 정체성 → 전투 → 세계라, 적을 정할 때 세력이 없었다. 어느 세계에나 붙일 수 있는 적이 나왔다.
3. **동료의 전투 행동에 재료가 없다.** 브리프 동료의 `함께 하는 일`은 삶의 사실이라 싸움에서 스스로 하는 행동이 되지 않았다(GDD에 "전투 중에도 재주를 가르친다").
4. **전투 후보 네 개를 닫힌 축 표로 채운다.** 클래스가 능력 두세 개만 쓰게 되면서(#99) 네 후보를 서로 세 축 이상 다르게 만들 재료가 더 좁아졌다.

## 결정

1. **사건은 구체적으로 쓴다.** 누가 어디서 무엇을 했고 무엇이 남았는지가 보이게 쓴다. 보편적 생애 사건 언어는 현대 제도 명사를 피하라는 뜻이지 추상어로 쓰라는 뜻이 아니다.
2. **세계를 전투보다 먼저 만든다.** 흐름은 정체성 → 세계 → 전투 → GDD다. 세계는 전투를 읽지 않고 전장에 그곳에서 맞서는 세력을 쓴다(`check-world`가 세력 이름을 확인).
   전투는 세계를 읽고, 적은 세계의 세력을 인용한다(`check-combat`).
3. **인물 사전에 그 인물의 `다루는 것`을 둔다.** 체계별 일생 해석이 그 인물의 자리에서 읽고, 통합 해석이 합치며, 브리프 동료의 `재주`로 옮긴다(`check-translation-brief`).
   전투는 동료의 행동을 `재주`로 쓰고 `함께 하는 일`의 관계와 어긋나지 않게 한다.
4. **전투 후보는 세 개다.** 쌍마다 세 축 이상 다르다는 조건은 유지한다. run 사이 수렴(#75)은 남는다.

## 검토한 대안

| 결정 | 대안 | 고르지 않은 이유 |
| --- | --- | --- |
| 세계를 먼저 | 전투는 적의 행동만, 세계는 적의 정체만 정한다 | 순서는 그대로지만 적의 정체를 세계가 나중에 붙이게 되어 전투의 적이 여전히 세계와 따로 만들어진다 |
| 인물의 다루는 것 | 동료의 전투 행동을 지어냄으로 허용 | 재료 없이 짓는 자리가 하나 더 늘고, 동료가 그 인물이 아니라 장식이 된다 |
| 후보 세 개 | 네 개를 두고 축 차이를 두 축으로 낮춘다 | 비슷한 후보가 늘고, 클래스 재료가 좁아진 문제는 그대로다 |

## 결과

- 바뀐 계약: 흐름 명세 2절 표와 5절, 세계·전투 스킬과 검증기, 일생 해석·통합의 인물 필드, 브리프 동료의 `재주`, 검토 에이전트의 입력 표, 재료 지도.
- 재료 지도의 알려진 재료 부족은 전투 후보의 수렴(#75) 하나만 남는다.
- 이 변경 전에 만든 일생 해석은 인물의 `다루는 것`이 없어 새 검증기를 통과하지 못하고, 이전 세계 문서는 전투를 인용해 새 검증기를 통과하지 못한다.
