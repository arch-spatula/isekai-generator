# ADR: 고정 GDD 출력 템플릿 기준선 0.4 채택

* **Status:** Accepted
* **Date:** 2026-11-08
* **Decision Owners:** Project Owner

## 결정

소유자가 요청한 출력 템플릿 확장은 아티팩트 결과에 영향을 주는 기능 추가이므로
기준선을 `0.3`에서 `0.4`로 승격한다. 개선 브랜치에서 검증한 구현과 이 근거를 먼저
커밋하고, 깨끗한 작업 트리에서 기존 승격 도구를 실행한 뒤 설정을 별도 커밋한다.
PR에는 이전·목표 series와 검증 결과를 기재하고 자동 merge하지 않는다.

## 변경과 검증

기존 컨셉 프롬프트를 고정 문서 제목과 11개 절의 출력 템플릿으로 바꾼다. 게임명과
세부 설계는 본문에서 달라질 수 있다. 생성 스킬과 두 작성 모드는 같은 템플릿을 읽고,
검증기는 제목·절 순서와 누락·빈 절을 검사한다. 기존 해석 근거, 전투·세계 구조와 공통
화면 계약 검사도 유지한다. 합성 입력으로 구조 위반과 정상 하위 제목·코드 블록을
검증하며 실제 개인 차트나 과거 로컬 아티팩트를 회귀 자료로 요구하지 않는다.

## 한계

구조 검사 통과가 기획의 재미나 의미적 완결성을 보장하지 않는다. 기존 의미 검토를
유지한다. 과거 아티팩트는 변경하거나 재번호 부여하지 않고 이번 승격만으로 새 결과를
생성하지 않는다. 해석 품질과 세계관 수렴의 기존 known issue는 그대로 유지한다.
