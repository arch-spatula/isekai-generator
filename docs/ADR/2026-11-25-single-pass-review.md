# ADR: 게임 설계 단계의 검토를 한 번으로 줄이고 재료 없는 요구를 없앤다

* **Status:** Accepted — 구현 #100
* **Date:** 2026-11-25
* **Decision Owners:** Project Owner
* **관련:** [이세계 정체성 설계](2026-11-24-isekai-identity-design.md) 결정 5, [Claude 게임 설계 흐름](../spec/claude-game-design-flow.md) 4.7,
  [검토 반복 인시던트](../incidents/2026-11-24-design-review-retry-loop.md), #100, #72, #92~#96

## 배경

이세계 정체성 ADR 결정 5(#72)는 정체성·전투·세계 단계를 다른 에이전트가 검토하고, 되돌리면 지적된 위치를 고쳐 다시 검토받게 했다(최대 3번).
로컬 run 세 개(원본은 저장소에 없음)의 검토 20번 중 통과는 3번이었고, 1회차 통과는 단계 8개 중 0개였다. 정체성과 전투는 대부분 3번째도 되돌림으로 끝났다.
회차마다 검토 에이전트가 새로 시작해 문서 2~4개를 다시 읽어, 비용이 단계 3개 × 최대 3회로 쌓였다.

지적은 같은 자리에 반복됐다. 장별 세계는 정체성 검토 8번 중 6번, 부직업이 생업을 옮겼다는 지적은 두 run, 전투 후보가 전형적인 네 자리를 채웠다는 지적은
전투 1·2회차마다 나왔다. 에이전트가 규칙을 어긴 사례(3회 상한 위반)도 있었지만, 반복의 대부분은 구조에서 나왔다.

1. **재료 없는 요구:** 작성자가 읽을 수 있는 입력에 재료가 없는데 지침이 그것을 요구했다(아래 표).
2. **열린 기준과 한 개 되돌림:** 투영·이세계다움은 정도의 판단인데 "사소해 보여도 지적"하고 하나만 걸려도 되돌렸다. 문제를 찾는 역할의 모델은 거의 항상 하나는 찾는다.
3. **매번 새로 보고 국소 수정:** 검토자는 이전 검토를 읽지 않아 회차마다 다른 곳을 지적했고, 작성자는 지적된 곳만 고쳐 새 위반이나 앞 회차 패턴으로 돌아갔다.

Codex 흐름도 생성 뒤 수정·방어 편집·리뷰를 겹겹이 쌓아 재시도 비용이 컸다. Claude 흐름은 처음에 그 구조를 없앴지만, 결정 5가 앞 단계의 재료 문제를 그대로 둔 채
뒤에서 걸러 고치는 루프를 다시 넣었다. 그때의 Codex 리뷰는 결정적 형식 계약이었고, 이번 검토는 열린 의미 기준이라 상한까지 도는 것이 기본값이 됐다.

## 결정

1. **검토는 단계마다 한 번이다.** 검토자는 기준에 걸리는 곳을 한 번에 모두 적는다. 작성자는 한 번 고치고 검증기를 통과시킨 뒤 끝낸다. 다시 검토하지 않는다.
2. **필수와 권고를 나눈다.** 모순(브리프 사실과 어긋남)과 직역(기호를 명사로 바꿈)은 있고 없음이 분명해 필수이고, 하나라도 있으면 `판정: 되돌림`이다.
   재해석·투영·이세계다움·비교는 정도의 판단이라 권고이고, 권고만 있으면 `판정: 통과`다. 작성자는 필수를 반드시 고치고, 권고는 반영하되 반영하면 다른 곳이
   어긋나는 지적은 그대로 두고 보고한다. `check-review`가 판정과 필수 지적의 유무가 맞는지 확인한다.
3. **재료 없는 요구를 없앤다.**

   | 요구 | 작성자가 읽는 재료 | 정리 |
   | --- | --- | --- |
   | 장별 세계: 주인공과 무관한 시대의 모습이면서 그 장의 사건이 일어날 수 있게 | 브리프의 장(주인공 사건만) | 출신 도시의 산업·권력에서 사건의 무대가 될 시대 변화를 짓는다. 사건과 맞물리는 것은 결함이 아니고, 사건의 주어만 공동체로 바꾼 되풀이만 지적한다 |
   | 부직업: 생업을 재료로 쓰되 생업을 옮기지 않게 | 브리프의 생업 | 부직업은 생업에서 오는 자리다. 이세계의 수요와 클래스와 맞물리는 방식이 있으면 되고, 생업이 부직업이 된 것 자체는 지적하지 않는다 |
   | 세계의 지역: 장의 사건이 일어나는 곳이면서 사건을 되풀이하지 않게 | 정체성의 장별 세계, 브리프의 장 | 장별 세계와 같은 규칙 |
   | 출신 도시: 배경에서 나온 구체적인 곳 | 브리프 배경(#97에서 생활 기반을 더함) | #97에서 다룬다 |
   | 전투 후보: 닫힌 축 표에서 고르되 같은 네 자리를 채우지 않게 | 브리프 능력, 전투 원형 축 표 | 비교는 권고로 낮춘다. 후보가 축 표로 수렴하는 문제 자체는 #75에서 다룬다 |

## 검토한 대안

| 결정 | 대안 | 고르지 않은 이유 |
| --- | --- | --- |
| 검토 한 번 | 검토를 없애고 작성자가 판별 질문으로 스스로 확인 | 같은 에이전트의 자기 확인은 자기 판단을 근거로 통과시키기 쉽다(결정 5의 이유). 다른 눈 한 번은 남긴다 |
| 검토 한 번 | 최대 3번을 두고 기준만 좁힌다 | 회차는 줄 수 있어도 비용 상한이 그대로이고, 재료 없는 요구가 남으면 같은 자리가 계속 걸린다 |
| 필수는 모순·직역 | 투영도 필수로 둔다 | 투영은 정도의 판단이라 매번 걸릴 거리가 있다. 필수로 두면 재검토 없이 끝내는 구조와 맞지 않는다. 출신 도시 투영은 #97에서 재료를 고쳐 줄인다 |

## 결과

- 바뀐 계약: [Claude 게임 설계 흐름](../spec/claude-game-design-flow.md) 4.7, 정체성·전투·세계 스킬 5절, 검토 에이전트 2·3절, `check-review`.
- 이 결정으로 #93(일부만 지적)·#94(상한 위반)·#95(회귀)는 재검토가 없어져 해당 구조가 사라진다. #92(전투 제외 이유 기준 충돌)와 #96(첫 시도 위반)은 권고로 낮아졌지만 기준 자체는 남는다.
- 판정은 같은 조건으로 생성한 여러 명식에서 검토 회차, 필수 지적 수, 반복 지적 자리를 전후로 비교하고, 목표에 닿았는지는 산출물을 열어 따로 본다.
