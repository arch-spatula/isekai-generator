# ADR: 스토리 영감용 해석의 방어 문구를 생성 지시와 사후 편집에서 제거

* **Status:** Accepted — 구현 미반영
* **Date:** 2026-11-09
* **Decision Owners:** Project Owner
* **Scope:** 전문 해석·통합 해석 에이전트 호출 지시와 생성 후 편집

## Context

차트 해석은 개인화된 스토리와 게임의 영감으로 활용한다. 그러나 생성 과정에서
요청하지 않은 사건 예측을 부정하거나 결과의 성격을 해명하는 방어 문구가 반복됐다.
[해석 품질 인시던트](../incidents/2026-11-03-interpretation-prompt-quality.md)에 기록한
사례에서는 부분 수정 뒤에도 지적 문구가 유지되거나 다른 위치에 같은 유형의 문구가
남아 통합 단계가 중단됐다.

현재 금지 표현 검사는 특정 문자열을 감지한다. 이것만으로 문장의 필요성을 판단하거나
문제 부분이 실제로 보강됐는지 확인할 수 없다. 생성 시 목적을 명확히 전달하고,
생성 후에도 불필요한 방어 문구를 편집하는 방향을 채택한다.

## Decision

1. 전문 해석과 통합 해석 에이전트를 호출할 때, 결과가 스토리·게임의 영감으로
   활용된다는 목적과 불필요한 방어 문구를 넣지 말라는 지시를 명시한다.
   예언·진단·사건 확정을 부정하는 상투적 설명을 덧붙이기보다 제공된 근거의
   성향·관계·갈등·발현 조건을 직접 해석하도록 한다.
2. 사후 편집에서도 해당 목적에 필요하지 않은 방어 문장이나 절을 제거한다.
   제거로 답변이 비면 해당 부분만 근거에 기반한 해석으로 보강하고,
   유효한 나머지 해석과 근거 연결은 보존한다. 같은 의미의 다른 표현으로 바꾸어
   금지 문자열 검사만 통과시키는 편집은 하지 않는다.
3. 계산 전제와 자료 범위에 필요한 정보는 보존한다. 예를 들어 잠정 생시 사용,
   계산에 없는 요소의 부재, 조건에 따른 대안적 발현은 의미에 따라 구분한다.
   불필요한 방어 문구를 제거한다는 이유로 근거 없는 확신이나 계산에 없는 사실을
   추가하지 않는다.
4. 이 목적 설명은 해당 단계의 공유 지침이나 명시적 호출 계약에 반영한다.
   원시 출생정보·대화 이력·다른 단계의 산출물을 추가 전달하는 근거로 사용하지 않는다.
5. 편집 뒤에는 수정 문서 전체의 기존 검증과 근거 보존 검토를 수행한다.
   통과한 전문 해석을 다시 생성하거나 전체 파이프라인을 재해석하는 것으로 확대하지 않는다.

## Consequences and Validation

생성 단계에서 불필요한 문구를 줄이고, 남은 문구는 사후 편집에서 처리한다.
문자열 검사만으로 의미 품질이 보장되지는 않으므로 다음 사례를 구분해 검토해야 한다.

- 불필요한 예측 부정 문구가 생성 지시 및 편집을 통해 제거되는 사례
- 잠정 입력·자료 부재·대안적 발현에 필요한 설명이 보존되는 사례
- 문제 부분의 해석은 보강되면서 유효한 항목과 근거 연결은 유지되는 사례
- 한 위치를 수정한 뒤 다른 위치에 같은 유형의 문제가 남는 사례

이 ADR은 방향의 채택 기록이다. 호출 계약·스킬·편집 절차·validator의 변경이나
새 회귀 검증은 아직 수행하지 않았다. 별도 편집 에이전트의 신설, 재시도 예산 변경,
기존 종료 실행의 재개 및 생성 기준선 승격도 이 결정만으로 수행하지 않는다.
