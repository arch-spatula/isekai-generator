# ADR: Pixelbolt를 활용한 코드 기반 이펙트 제작 계획

* **Status:** Accepted — 활용 계획 채택, 설치·게임 통합 및 시각 품질 검증 전
* **Date:** 2026-11-09
* **Decision Owners:** Project Owner
* **Scope:** LÖVE2D 탑다운 픽셀 Action RPG의 이펙트 제작

## 배경

세피리아 같은 탑다운 픽셀 액션 게임을 구상하며, 이펙트 제작 원본도 최대한 코드로
관리하고자 한다. 완성 이미지의 수보다 팔레트, 픽셀 크기, 공격 방향과 타이밍을
게임에 맞추고 변경 내용을 검토할 수 있는지가 중요하다.

pixelfx의 일부 검격과 지면 효과는 탑다운 화면에 맞게 원근과 형태를 수정해야 한다.
Pixel Composer는 노드 편집과 CLI 자동화를 제공하지만, 텍스트 원본을 직접 수정하는
작업 흐름에는 JSON 레시피를 사용하는 Pixelbolt가 더 적합하다고 판단한다.
이 판단은 공식 문서와 소스 조사에 근거하며, 실제 게임 화면에서 비교 검증한 결과는 아니다.

## 결정

[Pixelbolt](https://github.com/skulitom/Pixelbolt)를 코드 기반 이펙트 제작의 우선 검증
도구로 선택한다. 먼저 대표 효과를 검증한 뒤 실제 게임 제작에 사용할 범위를 정한다.
이번 결정으로 도구 설치나 게임 통합이 완료된 것으로 보지 않는다.

- JSON 레시피를 편집 가능한 원본으로 관리하고 CLI로 PNG 스프라이트시트와 프레임
  메타데이터를 생성한다. 원본과 생성 명령, 옵션, 도구 버전 또는 커밋을 함께 기록한다.
- 재사용할 제작 원본은 Git에서 관리한다. 로컬 실험 결과는 기존 로컬 아티팩트 정책을
  따르며, 게임 배포에 필요한 출력의 저장 위치는 통합 시 정한다.
- LÖVE2D는 출력된 이미지를 재생한다. Pixelbolt나 Node.js를 게임 실행의 필수 의존성으로
  추가하지 않는다. 프레임 시간, 피벗과 공격 방향을 게임의 애니메이션에 연결한다.
- 먼지·불씨처럼 실시간 움직임이 필요한 보조 효과는 필요에 따라 Lua 파티클로 구현한다.
  Pixelbolt가 모든 런타임 효과를 대신한다고 가정하지 않는다.
- Pixel Composer는 시각적 노드 편집이 필요한 경우의 대안으로 남긴다. pixelfx도 개별
  보조 효과 후보로 유지하되 여러 도구를 동시에 도입하는 것을 선행 조건으로 삼지 않는다.

## 검증 계획

1. 작은 피격 효과, 기본 검격, 지면 광역 마법을 각각 하나씩 제작한다. 공식 예제의
   8방향 투사체 지원을 모든 효과의 탑다운 원근 지원으로 해석하지 않는다.
2. 동일한 원본·옵션·고정 도구 버전으로 재생성했을 때 이미지 픽셀과 프레임 정보가
   동일한지 확인한다. 프레임 잘림과 피벗 오차도 검사한다.
3. 게임 배경과 캐릭터에 합성해 픽셀 크기, 팔레트, 지면 원근, 공격 방향과 타격 시점을
   검토한다. 발광·입자·잔상은 전투 가독성에 맞게 조정한다.
4. 다수의 적을 연속 공격하는 장면에서도 플레이어와 적의 공격 예고가 식별되는지 확인하고,
   대상 실행 환경에서 효과 중첩 시 프레임 시간과 메모리 사용량을 측정한다.

재생성, 시각적 조화, 전투 가독성과 대상 환경의 성능 기준을 모두 통과한 효과부터 사용한다.
성능 목표와 측정 환경은 게임 프로토타입에서 명시한다. 현재는 도구 실행·시각 품질·성능이
미검증이며, 검증 실패 시 효과 수정 또는 다른 제작 방식으로 전환한다.

## 비용과 라이선스

2026-11-09에 확인한 Pixelbolt의 소스는 MIT 라이선스이며, README는 포함된 아트워크도
같은 라이선스라고 명시한다. 로컬 CLI 사용에는 필수 API 키나 유료 네트워크 서비스가 없다.
AI를 이용한 레시피 작성 비용은 사용하는 AI 서비스에 따라 별도로 발생할 수 있다.

- 도구 코드 또는 동봉 예제·아트워크를 복사·수정해 배포할 때 해당 저작권 고지와 MIT
  라이선스 전문을 배포물의 제3자 고지에 보존한다.
- MIT는 이 도구를 사용한 게임 전체의 소스 공개를 요구하지 않는다. 직접 작성한 레시피의
  출력이 도구 사용만으로 MIT 적용 대상이 된다고 보지 않는다. 외부 입력 소재의 조건은
  별도로 확인한다.
- 실제 도입 버전의 LICENSE와 포함 소재 고지를 다시 확인해 기록한다.

Pixel Composer도 공개 소스는 MIT지만, 조사 당시 공식 itch.io 실행 파일은 15 USD 이상에
판매되며 데모가 제공된다. 소스 직접 빌드에는 GameMaker 환경이 필요하다.

## 결과와 한계

레시피와 생성 절차를 함께 관리하면 AI 또는 개발자가 수정한 내용을 검토하고 이펙트를
다시 생성할 수 있다. 반면 출력의 미술 품질은 도구 선택만으로 보장되지 않으며, 팔레트와
탑다운 원근을 맞추는 작업 및 LÖVE2D 재생 연결이 필요하다.
