# ADR: 속성은 세 체계의 기운 사실과 하는 일을 함께 읽어 정체성에서 정한다

* **Status:** Superseded by [최소 지시 GDD 에이전트](2026-11-28-minimal-gdd-agent.md)
* **Date:** 2026-11-27
* **Decision Owners:** Project Owner
* **관련:** [게임 칸](2026-11-26-game-slots.md) 결정 1·2(속성 칸), #115(이 결정), #111

## 배경

칸 목록 결정은 속성을 "타고난 지속 성질"로 두고, 명식(세 체계를 종합한 기운)과 직업 특성(브리프의 재능·생업)을 함께 보고 해석하게 했다.
오행 밖의 속성(번개·암흑·신성 등)과 무속성도 된다. 차트에서 칸으로 바로 가는 재료는 스크립트가 판정 없이 계산한 사실만 허용한다.
무엇을 계산해 어디로 넘길지는 이 결정에 맡겼다.

## 결정

1. **스크립트 `attribute-facts`가 세 체계의 사실 파일에서 기운 사실을 계산한다.** 판정하지 않고 차트 명칭 없이 일상어로 낸다.
   - 동양 다섯 기운의 분포(여덟 자리), 중심 기운, 태어난 계절
   - 두 번째 체계의 바탕 기운
   - 서양 네 원소와 움직임(시작·고정·변화)의 분포
   - 삶의 중심 둘레의 길한 기운과 거친 기운의 수
   - 길한 별과 거친 별 가운데 본질적 품위로 힘을 얻은 수와 잃은 수. 어느 별이 길하고 거친지는 사실 파일의 섹트 소속 줄을 따른다
2. **정체성 단계가 속성을 정한다.** `identity.md`에 `## 속성` 항목 하나를 두고 `기운`(무엇을 보았나)·`재료`(브리프의 능력이나 생업 인용)·`판단`을 쓴다.
   항목 이름이 장르 어휘의 속성 이름이다. 가장 많은 기운이나 중심 기운 하나를 그대로 옮기지 않고, 기운 사실 없이 재능만으로 정하지 않는다. 대응표는 두지 않는다.
3. **전투가 속성을 입힌다.** `전투 방식`에 `속성` 필드를 두고, 정체성의 속성이 핵심 행동에서 어떻게 드러나는지 쓰고 인용한다. 새 속성을 정하지 않는다.
4. **GDD 주인공 절이 속성을 인용한다.**

## 검토한 대안

| 결정 | 대안 | 고르지 않은 이유 |
| --- | --- | --- |
| 분포에 길흉의 결을 더한다 | 기운 분포만 넘긴다 | 분포만으로는 번개·암흑·신성 같은 속성을 기운에서 읽을 근거가 없고, 특수 속성이 직업 특성만으로 정해진다 |
| 사실을 넘긴다 | 스크립트가 대응표로 속성 후보를 낸다 | 칸 ADR이 해석은 에이전트가 하도록 정했다. 대응표는 같은 분포에 같은 속성을 내서 사람을 가르지 못한다 |
| 정체성에서 정한다 | 전투 단계에서 정한다 | 속성은 클래스와 함께 이 사람의 성질이고, 전투는 정체성의 클래스 안에서 후보를 만든다. 전투에서 정하면 GDD 주인공 절이 전투 문서에 기대야 한다 |
| 전투에 입힌다 | 정체성과 GDD에만 둔다 | 액션 게임에서 속성이 싸움에 드러나지 않으면 이름만 남는다 |

## 결과

- 바뀐 계약
  - 스크립트: `bun scripts/attribute-facts.ts <디렉터리>`(입력 `saju-facts.md`·`ziwei-facts.md`·`natal-facts.md`)
  - 정체성: 섹션은 클래스 후보·클래스·속성·부직업·출신지. 속성은 항목 하나, `기운`·`재료`·`판단`
  - 전투: `전투 방식 > 속성`에 `[identity:<속성>]`
  - GDD: 주인공 절에 `[identity:<속성>]`
  - 정체성·전투·GDD 스킬과 검증기, 검토 기준, 흐름 명세, 재료 지도
- 정체성 단계의 입력 격리 예외는 이 스크립트 출력뿐이다. 정체성 스킬은 사실 파일을 직접 읽지 않는다.
- 이 변경 전에 만든 정체성·전투·GDD 문서는 새 검증기를 통과하지 못한다.
- 판정은 다시 생성한 결과에서 본다. 표본 하나로는 경향을 말하지 않는다.
  - 서로 다른 명식에서 속성이 갈리는가(다섯 기운 중 하나로 수렴하지 않는가)
  - 속성의 `판단`이 기운 사실과 하는 일을 모두 쓰는가
  - 전투의 `속성`이 핵심 행동에서 실제로 보이는가
