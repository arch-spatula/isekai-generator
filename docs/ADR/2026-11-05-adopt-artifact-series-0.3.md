# ADR: 진행 기록을 포함한 생성 기준선 0.3 채택

* **Status:** Accepted
* **Date:** 2026-11-05
* **Decision Owners:** Project Owner

## 결정

프로젝트 소유자의 “이제는 v0.3.x” 선언에 따라 진행 기록과 중단 후 인계 힌트를 포함한
현재 생성을 `0.3` 기준선으로 채택한다. 구현 검증과 commit 후 깨끗한 작업 트리에서
기존 승격 도구를 실행하고 설정을 별도 commit한다. 다음 새 예약은 `v0.3.0`부터 시작한다.
이번 작업에서는 실제 생성이나 버전 디렉터리 예약을 실행하지 않는다.

## 버전 자동화의 범위

- 일반 생성은 활성 series 안에서 patch를 자동 증가시킨다.
- 사용자에게서 새 minor 채택 의사가 명시되면 이를 승격 권한으로 받아 기록·검증·commit·
  승격 절차를 수행한다. 같은 전환 의사를 다시 묻도록 하지 않는다.
- 코드나 프롬프트가 바뀔 때마다 minor를 추측해 올리지는 않는다.
- 이전 아티팩트는 이동·재번호 부여하거나 TODO를 소급 생성하지 않는다.

## 채택한 변경과 남은 한계

루트 TODO는 예약 즉시 만들어지고 차트·전문 해석·부모 상태 변경 시 자동 갱신된다.
나머지 단계도 시작·검증 완료 체크포인트를 기록하도록 스킬에 연결한다. 중단 후에는
같은 run의 기록과 실제 산출물을 대조하며, 종료된 실행을 자동으로 다시 열지 않는다.

의미가 같은 책임 회피 서술의 재발은 아직 미해결이다. 해양 세계관 수렴에 대한 대표
입력군 회귀 비교도 남아 있다. 이 승격은 그 문제가 해결됐다는 선언이 아니며 두 incident를
known issue로 유지한다. 소유자의 채택 의사에 따라 이 회귀 비교는 후속 과제로 둔다.
