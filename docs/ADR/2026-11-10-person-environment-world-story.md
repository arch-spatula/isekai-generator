# ADR: 인물과 주변 환경의 해석을 구분해 세계관과 스토리 설정에 활용

* **Status:** Accepted — 구현 미반영
* **Date:** 2026-11-10
* **Decision Owners:** Project Owner
* **Scope:** 전문·통합 해석의 의미 보존과 세계 후보·GDD의 세계관 및 스토리 설계

## Context

개인화 게임은 사람의 성향뿐 아니라 그 사람이 어떤 환경과 관계를 맺고 어떤 선택을
하게 되는지도 다룬다. 내적 욕구와 외부 조건을 모두 같은 성격의 모티프로 취급하면
주인공의 성향이 지형·사회·적대자에 반복 투영되고, 주인공과 구별되는 세계의 논리와
스토리의 갈등 조건이 약해질 수 있다.

현재 지침에는 두 종류의 재료가 이미 있다.

- [자미두수 해석](../prompts/ziwei-interpretation.md)은 명궁의 정체성과 선택 방식 외에
  천이궁의 외부 환경, 교우궁의 사회적 협력, 전택궁의 생활 기반, 부모궁의 지원·기대를 다룬다.
- [사주 해석](../prompts/saju-interpretation.md)은 원국과 관계 작용, 환경에 따른 발현,
  운의 변화를 다룬다. [네이탈 해석](../prompts/natal-interpretation.md)은 심리 기능과
  삶의 영역, 내적 동기·행동·환경 반응의 연결을 다룬다.
- [통합 스킬](../../.agents/skills/interpret-chart-report/SKILL.md)은 내적 동기에서 행동,
  환경 반응, 반복 결과로 이어지는 인물 모델을 만들지만, 세계 설계에 사용할 환경 해석을
  개인 성향과 구별해 전달하도록 명시하지는 않는다.
- [세계 선택 스킬](../../.agents/skills/select-world-concept/SKILL.md)과
  [후보 계약](../../.agents/skills/select-world-concept/references/selection-contract.md)은
  통합 해석의 패턴을 공간 규칙과 플레이어의 결정으로 변환한다. 환경 관련 해석을
  우선 활용하는 계약은 없으며, 비교 축도 주로 지형·생태·이동·정착·위험·공간 논리다.
- [GDD 스킬](../../.agents/skills/generate-gdd-from-interpretation/SKILL.md)은 선택된 세계의
  공간 계약을 보존하며 지역과 관계를 구체화하지만, 인물과 환경 해석의 설계 용도를
  구분하지 않는다.

이는 지침의 정적 검토 결과다. 특정 생성 결과의 품질 저하나 원인을 실증한 기록은 아니다.
현재 계약은 내적 성향을 세계화하는 방식과 환경 해석으로 배경을 만드는 방식을 모두
허용하므로, 후자를 의도적으로 활용할 설계 원칙이 필요하다.

## Decision

1. **인물 자체와 주변 환경에 관한 해석을 의미에 따라 구분한다.** 욕구·기질·판단·행동은
   인물의 작동 방식으로, 지원·기대·제약·기회·생활 기반·타인과의 관계는 그 인물이
   마주하는 조건으로 읽는다. 둘이 함께 있는 항목은 관계를 보존하고 구분 가능한 부분을
   드러낸다. 차트 체계나 궁·하우스 이름만으로 일괄 분류하지 않는다.
2. **세계관과 스토리의 배경에는 환경에 관한 해석을 우선 활용한다.** 해석된 외부 조건을
   사회·공동체·거주 기반·자원 접근·이동 기회·권력 관계의 창작 근거로 삼는다. 주인공의
   내면을 세계 전체에 그대로 확대하기보다, 세계와 타인이 자체 목적과 제약을 가지고
   주인공에게 기회와 압력을 제공하도록 설계한다.
3. **스토리는 인물과 환경의 상호작용에서 만든다.** 인물의 욕구·선택 방식과 환경의
   지원·요구·저항이 만나는 지점에서 사건, 관계 갈등, 선택의 대가와 변화를 도출한다.
   주변 인물을 주인공의 성향을 설명하기 위한 도구로만 만들지 않는다. 세계의 모든 문제를
   주인공의 내적 결함에 대한 비유로 환원하지 않는다.
4. **해석과 창작의 경계를 유지한다.** 환경에 관한 차트 해석은 창작의 영감이며 실제
   출생 가정·사회 계층·가족사·사건을 확인한 사실로 취급하지 않는다. 실제 직업·가족
   관계를 판타지 직업·세력·사건에 그대로 복제하지 않고 관계의 작동 원리를 추출한다.
   근거가 부족하면 환경 해석을 새로 만들어 채우지 않으며 창작으로 추가한 설정과 구분한다.
5. **기존 개인화 및 공간 계약을 보존한다.** 원시 출생정보나 대화 이력을 세계 선택에
   추가 전달하지 않는다. 전문·통합 해석 단계는 생활 해석을 보존하고 게임 설정을 미리
   선택하지 않는다. 세계 후보 비교, 확정된 전투 동사, 공간 연결·관문·귀환·정착 규칙을
   유지하면서 환경 해석을 세계와 서사의 구체성으로 발전시킨다.

내면의 상징적 세계화도 작품에 필요하면 사용할 수 있다. 다만 환경 해석을 활용하지 않고
모든 설정을 내면의 반복 비유로 만드는 기본 경로로 삼지 않는다. 인물과 환경은 서로
영향을 주므로 완전히 독립된 두 목록으로 분리해 인과관계를 잃는 것도 피한다.

## Design Example

다음은 실제 개인의 차트나 생성 결과가 아닌 합성 예다.

| 구분 | 해석 재료 | 창작에서의 활용 |
| --- | --- | --- |
| 인물 | 자율적인 선택을 중시하고 도움에 의존하는 것을 어려워함 | 주인공의 동기와 협력 여부를 결정하는 방식 |
| 환경 | 공동체의 지원은 크지만 구성원에게 규범 준수와 역할 수행을 요구함 | 보호와 보급을 제공하되 출입·자원 이용에 의무를 부과하는 공동체 |
| 상호작용 | 지원을 받으면 행동의 자유에 제약이 생김 | 도움을 받아 위험 지역에 진입할지, 비용을 감수하고 독립 경로를 열지 선택하는 사건 |

스토리의 갈등은 주인공의 자율성만으로 만들어지지 않는다. 공동체의 보호 체계가 필요한
이유와 주민들의 이해관계도 설정해야 선택에 설득력이 생긴다. 공간 설계에서는 그 조건을
보급 거점·통행 제한·우회 경로·귀환의 대가로 구체화할 수 있다.

## Alternatives and Consequences

- 통합 해석 전체를 구분 없이 모티프 저장소로 사용하면 현재 구조를 유지하기 쉽지만,
  인물·환경의 차이를 설계에 활용한다는 목적이 보장되지 않는다.
- 모든 세계 설정을 환경 항목에서만 가져오도록 강제하면 혼합된 해석의 인과관계를
  끊고 필요한 창작을 제한한다. 우선 활용 원칙과 근거 구분을 채택한다.
- 특정 궁이나 하우스를 환경 전용으로 지정하면 심리·관계·생활 조건이 함께 있는
  해석을 잘못 분리할 수 있다. 항목의 실제 의미를 기준으로 판단한다.

이 결정은 세계의 독립적인 논리와 인물의 선택이 맞물리는 스토리 설정을 강화하려는
방향이다. 의미를 구분하고 검토하는 비용이 늘며, 분류 라벨이나 근거 ID의 존재만으로
세계관·서사의 품질이 입증되지는 않는다.

## Follow-up and Validation

후속 구현에서는 전문·통합 해석, 세계 선택, GDD 지침과 전달 형식을 함께 검토한다.
필요한 최소 표현 방식을 정하고 기존 근거 ID·전문 해석 보존·입력 격리와 양립하는지
확인한다. 새 에이전트·산출물·지문 축·점수 체계의 신설은 이 ADR에서 결정하지 않는다.

개인정보와 과거 로컬 결과 없이 사용할 수 있는 합성 사례로 다음을 검토한다.

- 개인의 성향과 외부의 지원·제약이 구분되고 두 요소의 상호작용이 보존되는가?
- 같은 내적 욕구에 다른 환경 조건을 주었을 때 세계와 사건의 차이를 설명할 수 있는가?
- 같은 환경에서 서로 다른 인물이 다른 선택과 관계 변화를 만드는가?
- 세계의 공동체·인물·제도가 주인공과 구별되는 목적과 작동 이유를 가지는가?
- 환경 관련 근거가 부족한 경우 실제 배경을 단정하거나 없는 해석을 보충하지 않는가?
- 선택한 세계의 공간 규칙과 전투 계약을 보존하면서 관계·사건·선택이 연결되는가?

구조·근거 참조 검증과 세계관·서사의 의미 품질 평가는 구분한다. 합성 사례 검토는
실제 모델의 생성 품질 개선이나 재미를 실증한 결과로 보고하지 않는다.
문서 검사는 `bun run check:docs`, `bun run check:docs --review`, `git diff --check`로 수행한다.

현재 변경은 결정 기록뿐이다. 스킬·프롬프트·validator의 변경, 새 생성 실험, 기존 결과의
수정과 활성 생성 기준선 승격은 수행하지 않는다.
