# ADR: 반복되는 실패를 플레이 시스템으로 옮기고 플레이어용 이름을 따로 둔다

## 배경

주인공이 반복해서 기우는 쪽(브리프의 `반복되는 실패`)은 GDD의 서술 문장에만 있었고 전투 시스템과 연결되지 않았다. 로컬 run v0.5.16(원본은 저장소에 없음)에서
"확신이 강할 때 혼자 밀어붙여 그르친다"는 주인공 절과 서사의 변화 절에만 나왔고, 전투의 약점은 능력의 막히는 조건에서 따로 왔다.
게임에서 그 사람의 사고방식을 가장 강하게 보여 주는 것은 플레이어가 반복하는 동작이다. 반대로 스토리에서 주인공이 정해진 실수를 하면
플레이어는 자기가 고르지 않은 실수를 떠안게 되어 분신이라는 느낌이 깨진다.

이 사고방식을 시스템으로 옮기면 이름 문제가 생긴다. 심리 용어를 그대로 이름으로 쓰면("확신 스택", "확신사") 주제를 소리 내어 말하는 꼴이 되어 어색하다.
장르 어휘는 심리가 아니라 플레이 방식을 가리키므로 자연스럽다. 시스템이 왜 들어갔는지는 엔딩 크레딧에서 사후에 설명해도 된다(사용자 결정).

직역 금지가 생긴 이유는 기호의 뜻을 세계의 명사로 옮긴 실패(武曲 → 장부 도시, 2026-11-23 ADR)였다. 이 금지는 장소와 직업 명사를 겨냥하고,
장르 어휘로 플레이어용 이름을 짓는 것과는 충돌하지 않는다. 그래서 직역 금지는 그대로 둔다.

## 결정

1. **전투 설계에 `끌림`을 둔다.** 항목 하나이며 재료는 `[brief:반복되는 실패]`다. 필드는 다음과 같다.
   - `쌓는 행동`: 플레이어가 그쪽으로 기울 때 하는 조작
   - `보상`: 그렇게 했을 때 얻는 이득
   - `대가`: 반복되는 실패의 구조를 남긴 위험
   - `기록`: 게임이 세어 두고 동료의 반응과 장면에 남기는 것
   - `극복`: 장이 지나며 시스템이 바뀌는 방식
   - `플레이어용 이름`
2. **`장별 끌림`을 둔다.** 브리프의 장마다 그 시기에 이 끌림이 무엇을 시험하는지 쓴다. 사람은 시기마다 고민이 다르므로 #109가 넘긴 장의 `고민`·`시련`이 재료다.
3. **지켜야 할 것은 지침과 검토가 본다.**
   - 구조를 남긴다. 능력치 교환만 남기지 않는다.
   - 조작을 빼앗지 않는다.
   - 쌓지 않으면 손해가 되도록 보상을 건다.
   - 결과를 정한 장면은 플레이어가 그쪽을 골랐을 때만 일어난다.
   - 검증기는 필드와 인용만 본다.
4. **플레이어용 이름은 클래스와 끌림에 둔다.** `###` 제목은 설계용 이름으로 남아 인용과 크레딧에 쓰인다.
   - 플레이어용 이름은 장르 어휘로 짓고, 심리 용어와 차트 용어는 쓰지 않는다. 장르의 흔한 직업 이름도 된다(#120).
   - 장르에서 흔한 말이어도 된다. 검토의 이세계다움 기준은 이름의 흔함이 아니라 구조와 조합을 본다.
   - 다른 칸은 구현될 때 같은 형식을 따른다.
5. **GDD에 `크레딧` 절을 둔다.** 플레이어용 이름마다 항목을 두고, 설계 항목을 인용하며, 그것이 일생의 무엇에서 왔는지 쓴다.
   게임 안에서는 이름을 붙이지 않고 동작과 동료 반응으로 느끼게 하고, 크레딧에서 이름을 붙여 준다. GDD의 런과 성장은 끌림을 인용한다.

## 검토한 대안

| 결정 | 대안 | 고르지 않은 이유 |
| --- | --- | --- |
| 끌림을 시스템으로 | 스토리 사건으로만 건다(예: 무리하다 동료를 잃는 컷신) | 반복되는 실패는 한 번의 사건이 아니라 되풀이되는 패턴이다. 정해진 실수는 분신 느낌을 깨뜨린다 |
| 전투 설계에 둔다 | GDD의 런과 성장에만 서술한다 | 검증기가 볼 필드가 없고, 핵심 행동과 맞물리는지 같은 문서에서 볼 수 없다 |
| 장별 끌림 | 끌림 하나가 네 장 내내 같다 | 시기마다 고민이 다르다. 결함 하나가 모든 장을 대표하던 문제(#109)가 시스템에서 되풀이된다 |
| 플레이어용 이름 필드 | 심리 용어 금지어 목록으로 검사한다 | 단어 목록은 의미의 간접지표다. 다른 말로 같은 심리를 쓰면 통과한다. 검토가 본다 |
| 클래스와 끌림만 | 이름이 붙은 모든 항목에 둔다 | 플레이어가 먼저 보는 두 이름부터 시작한다. 나머지 칸은 구현될 때 따른다 |

## 결과

- 바뀐 계약
  - `identity.md` 클래스의 `플레이어용 이름`
  - `combat.md`의 `끌림`·`장별 끌림`
  - `gdd.md`의 `크레딧`과 런과 성장의 끌림 인용
  - 세 스킬, 세 검증기, 검토 기준, 흐름 명세, 재료 지도
- 이 변경 전에 만든 정체성·전투·GDD는 새 검증기를 통과하지 못한다.
- 판정은 다시 생성한 결과에서 본다. 끌림이 구조(예: 혼자, 정점에서의 붕괴)를 남겼는지, 플레이어용 이름에 심리 용어가 없는지 의미 검토로 따로 보고한다.
