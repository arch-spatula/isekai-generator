# ADR: 재능과 기질을 나누고 기질이 능력이 되지 않게 한다

* **Status:** Accepted — 구현 #99
* **Date:** 2026-11-25
* **Decision Owners:** Project Owner
* **관련:** [배경 해석](2026-11-24-chart-background-interpretation.md), [일생 해석](../spec/life-narrative-interpretation.md) 3절,
  [전투 수렴 인시던트](../incidents/2026-11-24-claude-combat-style-convergence.md), #99, #70, #71

## 배경

차트 해석 층이 재능을 읽는 자리와 기질·관계를 읽는 자리를 나누지 않았다. 로컬 run 두 개(원본은 저장소에 없음)에서 체계별 재능 6개 중 3~4개가
기질이나 관계에서 나왔다(사주 비겁·격국 → "같은 일을 하는 동료나 경쟁자", 네이탈 우세 원소 → "사람들의 힘과 기세", 자미두수 福德의 성정 → "이미 짜인 틀이나 방식",
자미두수 子女궁과 자식 판단 → "사람의 마음을 살피고 보살핀다"). 이것이 브리프 능력("무리를 이끄는 힘", "틀을 허무는 손")이 되고, 정체성의 클래스는 능력 다섯 개를 모두 묶었다.
배경(#97)과 같은 구조로, 기질을 담을 자리가 없어 기질이 재능 칸을 채웠다. 관계 차단(#71)은 브리프에서 관계 칸을 능력의 출처로 쓰지 못하게 했지만,
일생 해석이 관계 자리로 재능 항목을 만들면 브리프는 그 재능을 정상 출처로 인용했다. 네이탈 지침은 우세 원소를 재능의 출처로 지정하고 있었다.

## 결정

1. **재능 항목에 `기르는 기질`을 둔다.** 그 재능을 키우거나 막는 성정을 쓰는 자리다. 성정은 재능 항목이 되지 않는다. 기질이 재능을 길러내는 관계도 여기에 남는다.
2. **재능의 근거로 관계·기질 판단을 쓰지 않는다.** 세 체계 모두 짝·자식·제자 판단, 네이탈은 우세 원소를 재능 근거로 쓰지 않는다. 자미두수 재능의 근거는 관계 궁만일 수 없다.
   검증기가 확인한다. 사주 비겁은 십신 분포 한 항목으로 인용되어 검증기로 가를 수 없으므로 스킬 지침(재능 영역은 식상·재성·관성·인성의 자리)과 의미 검토가 맡는다.
3. **`막히는 조건`은 그 재능을 막는 사정에서 쓴다.** 성정만으로 쓰지 않는다(스킬 지침).
4. **브리프 능력은 재능을 줄이지 않고 옮긴다.** `하는 일`(재능의 내용)을 더한다. `기르는 기질`은 능력이 아니다.
5. **클래스는 능력을 모두 묶지 않는다.** 한 동작 안에서 맞물리는 두세 개를 고르고 나머지는 부직업·동료·퀘스트로 남긴다. 검토의 투영 기준에 "클래스나 전투가 성정으로 서 있는가"를 더한다.

## 검토한 대안

| 결정 | 대안 | 고르지 않은 이유 |
| --- | --- | --- |
| 재능에 `기르는 기질` 필드 | 일생 해석에 기질 절을 따로 둔다 | 기질이 어느 재능을 키우는지가 끊긴다. 재능 옆에 있어야 "성정이 재능을 키운다"가 남는다 |
| 근거 인용으로 확인 | `다루는 것`의 단어 목록으로 확인 | "사람과 무리"는 실제로 사람을 이끄는 재능에도 맞는 말이라 오탐이 난다. 의미를 단어로 판정하지 않는다 |
| 사주 비겁은 지침으로 | 십신별 자리 인용을 강제한다 | 사실 파일이 십신 분포를 한 항목으로 둔다. 강제하려면 사실 층을 바꿔야 해 이 이슈의 범위를 넘는다 |

## 결과

- 바뀐 계약: 일생 해석·통합의 재능 필드, `check-life-document`의 재능 근거 검사, 브리프 능력의 `하는 일`, 세 일생 해석·통합·브리프·정체성 스킬, 검토 기준.
- 이 변경 전에 만든 일생 해석은 `기르는 기질`이 없어 새 검증기를 통과하지 못한다.
- 판정은 같은 앞 단계로 다시 생성한 결과에서 재능·능력의 출처를 단계마다 열어 확인한다.
