# LÖVE 이펙트 실험

세피리아 같은 탑다운 픽셀 액션의 이펙트 표현을 살펴보는 독립 실행 실험입니다. 코드로 그린 참격·지면 충격파와 LÖVE 기본 `ParticleSystem`의 불꽃을 비교합니다. 완성된 게임 아트나 전투 시스템은 아닙니다.

LÖVE 11.5를 설치한 환경에서 저장소 루트에서 실행합니다. 별도 이미지, 라이브러리, 프로젝트 빌드는 필요하지 않습니다.

```sh
love experiments/love-vfx
```

| 입력 | 동작 |
| --- | --- |
| `1` | 중앙에 참격 |
| `2` | 중앙에 지면 충격파 |
| `3` | 중앙에 네이티브 파티클 불꽃 |
| `Space` | 중앙에 세 효과 동시 재생 |
| 마우스 왼쪽 클릭 | 클릭한 장면 좌표에 세 효과 동시 재생 |
| `R` | 모든 효과와 파티클 지우기 |
| `Esc` | 종료 |

320×180 캔버스를 nearest 필터와 정수 배율로 확대합니다. 창 크기에 따라 여백이 생기며 여백 클릭은 무시합니다. 도형과 파티클을 저해상도로 표시하는 실험이므로, 픽셀 아티스트가 프레임별로 다듬은 스프라이트의 윤곽·타이밍과는 차이가 있습니다. 조작 캐릭터, 피격 판정, 사운드와 카메라 연출은 포함하지 않습니다.

도형 효과는 수명이 끝나면 제거하며 최대 64개, 파티클은 최대 512개로 제한합니다. 반복 입력으로 상한에 도달하면 오래된 도형 효과가 제거되거나 추가 파티클 수가 제한될 수 있습니다.

외부 후보의 역할·유지보수 상태와 다음 비교 방향은
[이펙트 라이브러리 조사](../../docs/spec/love-vfx-library-review.md)에 기록했습니다.
