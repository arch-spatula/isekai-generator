# Interpretation document contract

Write the document in Korean with these headings exactly once and in this order:

1. `# 명식 해석`
2. `## 해석 원칙`
3. `## 체계별 관찰`
   - `### 사주팔자`
   - `### 자미두수`
   - `### 서양 점성술`
4. `## 교차 체계 종합`
5. `## 핵심 해석 항목`
6. `## 불확실성과 금지된 단정`

Under `## 핵심 해석 항목`, write one or more items headed `### I-01`, `### I-02`, and so on with unique sequential IDs. Every item must contain `해석:` and `근거:` lines and may contain an `불확실성:` line.

Keep observations distinct from synthesis. Do not extract creative motifs or include the complete source report or any GDD design.
