# Interpretation document contract

Write the document in Korean with these headings exactly once and in this order:

1. `# 명식 창작 해석`
2. `## 해석 원칙`
3. `## 체계별 관찰`
   - `### 사주팔자`
   - `### 자미두수`
   - `### 서양 점성술`
4. `## 교차 체계 종합`
5. `## 창작 모티프`
6. `## 불확실성과 금지된 단정`

Use `근거:` lines for major interpretations. Keep observations distinct from synthesis. Do not include the complete source report or any GDD design.
