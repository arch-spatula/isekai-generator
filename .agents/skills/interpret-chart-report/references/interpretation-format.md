# Interpretation document contract

Write the document in Korean with these headings exactly once and in this order:

1. `# 통합 차트 해석`
2. `## 해석 원칙`
3. `## 전문 해석 요약`
   - `### 사주팔자`
   - `### 자미두수`
   - `### 서양 점성술`
4. `## 교차 체계 비교`
   - `### 일관된 해석`
   - `### 구체성을 더하는 해석`
   - `### 상충하는 해석`
5. `## 핵심 해석 항목`
6. `## 불확실성과 금지된 단정`

Under `## 핵심 해석 항목`, write one or more items headed `### I-01`, `### I-02`, and so on with unique sequential IDs. Every item must contain `관계: 일관|구체화|상충`, `해석:`, and `근거:` lines and may contain `불확실성:`. Every evidence line must cite existing `S-`, `Z-`, or `N-` specialist IDs.

Keep specialist summaries distinct from synthesis. Do not extract creative motifs or include complete specialist documents or any GDD design.
